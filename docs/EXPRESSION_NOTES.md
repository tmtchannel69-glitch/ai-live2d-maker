# 表情素材の確認メモ

目や口の素材ごとに、問題と確認した状態を記録できます。AIの分離結果の境界確認とは別の記録です。自然な表情やモデルの完成を自動判定しません。

## 記録・再確認

1. 「表情を拡大して確認」で素材と開閉/向きを選びます。3状態比較では「この状態を詳しく」で先に一つを選びます。
2. 「この素材の確認メモ」で未確認/修正が必要/この状態は確認済みを選び、1000文字までのメモを入力します。
3. 「記録を反映」でアプリの作業に保持します。左右の目・口・向きの値、単独表示と元画像比較の条件も記録します。端末へ残すには別途「作業ファイルを保存」を使ってください。
4. 「記録した状態を表示」で記録値と表示条件を確認用の一時スライダーへ戻します。必要に応じて表示/形/範囲の編集へ移動します。

未反映の入力は同じ確認画面で素材を切り替えても役割ごとに保持します。画面を閉じる/保存処理を始める/リセット等では破棄し、その旨を入力欄の説明に表示します。確認済みは記録した状態と表示条件だけを指し、3状態全体や他の顔の向きの確認にはなりません。元画像比較を残した記録は元の絵が重なるため、比較を外した状態でも確認してください。

## 変更後の扱い

素材の追加/置換/削除/配置、表示/重なり、変形、固定/開閉範囲、親子のまとめ方、動きのキーを反映すると、残っている全記録へ再確認フラグを付けます。合成の見え方は他の素材でも変わるためです。同じ値を再反映した場合も保守的に再確認扱いにします。以前の状態・メモ・確認値は保持します。素材を削除した役割の記録はその素材とともに取り除きます。

スライダーや比較の操作、PNG/PSD/ZIP出力では再確認扱いにしません。再確認フラグのある記録を表示すると、現在の素材/設定に記録値を適用します。過去の画像や動きの設定を復元する機能ではありません。見直した後、「記録を反映」を押すと再確認フラグを外し、現在の記録へ更新します。

## 保存・引き継ぎ

- メモありの作業ZIPは版12。旧版1〜11も読み込み、メモは未記録として開始します。メモなしの作業は内容に応じて従来の版で保存します。旧アプリで版12を開く機能はありません。
- 作業JSONのexpressionNotesは役割ごとのstatus/note/pose/isolated/reference/stale。表示条件と値は具体的な確認文脈で、品質保証ではありません。
- メモありの制作引き継ぎZIPは版2で、handoff.jsonのexpressionNotesとEXPRESSION_NOTES.txtへ含めます。メモなしは従来の版1を維持。元画像は含めません。渡す前にメモの内容を確認してください。
- 動きの設定チェックのメモ行から確認画面へ移動できます。画像なし確認一覧にも記録と再確認状態を含めます。

不正な役割、未知の確認状態、1000文字超、範囲外の値、型/項目の不一致を読み込み前に拒否し、現在の作業を保持します。記録のための外部通信やクラウド自動保存はありません。スマホ実機・自然な表情の品質・moc3/VTube Studio読込は未完了です。
