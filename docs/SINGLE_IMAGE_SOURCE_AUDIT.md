# 完成画像1枚 → 33レイヤー：入力監査（オフライン先行工程）

2026-10-25。画像1枚を使う実際のワークフローの最初の検査画面を新設。分離済みPNGアップロード機能とは独立。ChatGPTによる画像生成・外部API接続は行わない。

## 操作（iPhone想定）

1. 「パーツからキャラ生成」を開く（基準キャラクターの作成は不要）。
2. 下の「画像1枚からの自動生成：入力画像の検査」で PNG / JPEG / WebP を1枚選ぶ（8 MiB以下）。
3. 画像を縦横比を保ったまま768×1024の透明キャンバスに収める。人間の顔や体の位置の自動検出・位置合わせはまだしない。
4. 基準デザインの33パーツ位置を選び、絵の上に候補領域枠を重ねて目視確認。矩形内の可視画素率・背景の透過・空画像・端の切れなどを記録。
5. 「基準画像と検査結果をZIP保存」で `normalized_reference.png`・`source_audit.json`・説明を出力する。

## 監査の意味と制限

- 一般的な完成イラストは1枚に描画内容が重なっている。矩形で33箇所を切るだけでは、背景・髪・肌・まつ毛などを独立したレイヤーへ復元できない。
- ZIP内の `normalized_reference.png` は完成絵を正規化した1枚であり、分割した33パーツではない。
- `source_audit.json` は33個の**仮の位置の矩形**と可視画素率を示す。可視率100%でも当該パーツを検出した意味ではない。人体認識やセグメンテーションを行っていない。
- 独立パーツ生成数0、隠れ面復元数0、AI生成未実施、動作設定未実施、品質未認定を常に明示する。一般公開できるLive2D/Cubismモデルを生成する機能ではない。
- 画像は端末内でデコード・分析。外部通信なし。ユーザーの許可がないAI画像生成APIや課金接続は追加しない。
- 画像の保持はこの画面を開いている間のみ。別の画像を選ぶと以前の結果は消える。元データは破壊しない。

## 次に本当に必要な研究工程

1. 人体ランドマーク・髪・目・口・衣服の**部位検出とマスク生成**（学習済み画像モデル等が必要）。
2. 画面上で隠された頭皮・顔・髪・服などの**隠れ面補完**（単純なマスク切り抜きでは不可）。
3. 33レイヤーの**相互位置、重なり、左右、境界、画風・同一人物性**の評価。
4. すべて揃ったものだけにInochi2Dのメッシュ・変形・まばたき・頭の動きを設定。
5. 公式Creator実機・iPhone Safariで品質判定。現段階ではどちらも未確認。
