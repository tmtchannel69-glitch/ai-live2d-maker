# 目・口の編集ガイド

「動きの設定チェック」の「目・口の編集ガイド」を開きます。左目（画面右）／右目（画面左）／口を選び、作業する素材を選択してください。元画像を読み込むと利用できます。

1. **素材を用意する**：役割ごとに読込済み／未読込を表示。「この素材を準備」は、その役割を選んで素材の読み込み画面へ移動します。読込済みは素材・位置の確認へ移動します。
2. **選んだ素材を調整する**：現在の状態から次の操作を案内します。表示・形・範囲の各ボタンでも移動できます。「形を調整」から「指で形を編集」と下書きの重なり確認へ進めます。
3. **動きを見て確認する**：閉じる／半分／開くを合成画面で試します。「拡大確認・メモ」で選択素材の詳細確認を開き、3状態比較や記録した状態の表示・確認メモを利用します。最後に作業ファイルを端末へ保存してください。

## 素材の区分

- 目の基本の目安：白目、瞳、まつげ・まぶた。
- 口の基本の目安：上唇、下唇、口の内部。
- 用途に応じた素材：別の閉じた目／口の画像、歯、舌。

基本は分けて動かす場合の目安で、すべての絵柄の必須条件ではありません。別画像の表示切替で試す方法もあります。元画像にない閉じた形・口内部・隠れた肌は自動生成しません。別途作成したPNGを用意してください。元の顔に目や口の絵が残ると、素材を動かしても背景に絵が残ります。下地の肌は「目・口の下地の肌」の役割で読み込み、必要な重なりを確認してください。

AI結果から役割へコピーする場合も、コピー先の白目・瞳などへの自動細分化は行いません。画像がその役割に適しているか利用者が確認してください。

## 次の操作の案内

選んだ素材について、次の優先順位で一つの候補を表示します。

1. 未読込 → 素材を準備。
2. 非表示 → 表示を確認。
3. 変形の開閉値が部位と違う → 形の設定を確認。
4. 開閉範囲の値が部位と違う → 範囲の設定を確認。
5. 修正・再確認のメモあり → メモから見直す。
6. 基本素材で変形未設定 → 開閉の形を調整（画像の切替で試すことも可能）。
7. 上記以外 → 拡大して形と重なりを確認。

設定の有無から作る案内です。自然な動き・素材の品質・モデルの完成を自動で判定しません。確認済みのメモがあっても確認対象は記録した状態だけです。範囲ははみ出す場合に設定し、すべての素材に要求しません。

## 保存と操作制限

部位・素材の選択とガイドの開閉はこの画面だけの状態で、画像・作業設定・確認メモを変更しません。作業ファイルの読込／元画像の変更でガイドは閉じ、左目へ戻ります。作業ZIP版1〜12と引き継ぎ版1／2の形式は維持します。

未読込の素材の編集・確認、部位の素材が一枚もないときの動き確認は無効になります。処理や保存中はガイドの操作を止めます。画像なしの「動きの確認一覧」には、各役割の読込状況と用途に応じた区分を追加します。ガイドの選択状態は保存しません。

実機スマホの操作性や自然な表情品質は別途検証が必要です。VTube Studio用moc3モデル出力は未実装です。
