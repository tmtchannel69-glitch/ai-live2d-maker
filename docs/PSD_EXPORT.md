# レイヤー付きPSDの設計・試作

オーナーの最新の「続けて」で設計・試作を承認。ブラウザ内で処理し、外部画像送信・契約・課金・公開は行わない。元画像とユーザー出力はGitHubに保存しない。

## 対象と形式

「レイヤー付きPSDを保存（試作）」でai-live2d-parts.psdをダウンロードする。表示中の構成で選択したAI結果だけを一項目一レイヤーにする。元画像の幅・高さと左上原点を維持し、トリミング・拡大縮小・マスクの再生成を行わない。反映済みブラシ補正も保存する。レイヤー名は日本語名とID（例：目・左（画面右） [eye_l]）で一意にする。

RGB・8ビット、通常合成、不透明度100%、全レイヤー表示、レイヤーマスク・グループ・効果なし。透明度はPNGの画素として保持し、不透明な最下層も背景レイヤーに固定しない。確認記録を持つ作業ファイルと制作素材ZIPは変更しない。

元画像・未選択・別構成の素材・結果なし項目は含めない。結果なしは画面で件数を案内し、制作素材ZIPの不足一覧で確認できる。デモは元画像上の位置を復元できないため対象外。指定変更前の結果も現在のPNGを保存し、再分離・再確認を案内する。PSDはアプリの作業ファイルとして読み込めない。

## 重なりと色の扱い

基本四分類は下から体・衣装→顔→髪→目。制作構成は後ろ髪→トップス→ジャケット→袖→首→顔→横髪→口→目→眉→前髪を初期順序とする。左右の同種項目は右→左。これは選択した画像から深さを推定したものではなく、画像編集ソフトで調整するための仮の順序。AIマスクの重なりを自動で取り除かない。

PNGを直接読み取り、半透明のRGB値がCanvasの乗算・逆乗算で変わることを避ける。8ビットのRGB/RGBA/グレースケールとインデックスPNGに対応し、16ビットなどはエラーで案内。ICC付きPNGは色の変換未実装のため拒否する。PSDへのICC埋め込み・色空間変換は未対応。画像編集ソフトでsRGBとして色を確認・保存する必要がある。レイヤー合成用の表示画像も作成するが、完成モデル・品質保証ではない。

公式の[インポートPSDの作り方](https://docs.live2d.com/cubism-editor-manual/reimport-psd/)・[PSD作成上の注意](https://docs.live2d.com/cubism-editor-manual/precautions-for-psd-data/)を設計の参照資料とする（従前の調査記録はPARTS_AND_EDITOR_DESIGN.md）。対象Cubismで実際に読み込むまでは「Cubism対応済み」と呼ばない。

## ライブラリと処理

- ag-psd 31.0.3（MIT、Agamnentzar）：ブラウザ対応のPSD読み書き。ラスターレイヤーと日本語名の出力に採用。
- fast-png 8.0.0（MIT、Michaël Zasso）：PNGを直接画素に変換、CRC確認。PSDへの画素一致を優先して採用。
- 両方をpackage.jsonとロックファイルで固定。再開時は既存のnpm ciで導入できる。runtime依存の利用条件をpublic/THIRD_PARTY_NOTICES.txtに収録。
- PSD作成はWorker内で行い、画面を操作できるようにする。リセット・新画像選択時はWorkerを終了し、遅い保存を抑止する。出力中は指定・選択・補正・他の保存を抑止する。失敗時に元の作業を保持する。

上限は元画像の各辺4096 px・1600万画素、各PNG32 MiB、入力PNG合計100 MiB、出力100 MiB。レイヤー全体と合成画像のRGBA画素量は128 MiBまでとし、超過はデコード前に案内。これは総メモリの保証ではなく、ライブラリの一時領域・出力バッファ等の追加負荷はある。最大サイズと実機スマホは未検証。項目を減らすか素材ZIPを使用できる。

## 検証と未確認事項

- 既存ブラウザ27件が成功。新規PSD三件はテストの詳細欄を二度開閉する問題と、依存関係更新時の開発サーバー再読み込みを解消し、再実行で成功。画素合成の小さな最適化後もPSD三件を再実行して成功。合計30種類のケースを確認した。実AI応答は代替APIで、モデル変更・実推論再評価はない。
- 出力PSDをag-psdで読み戻し、日本語の一意な名、RGB8ビット、元キャンバスと各レイヤー位置、不透明度、透明画素を含むRGBAと補正済みPNGの全画素一致を検証。alpha=0/1/128/255を含む。未選択・別構成・未生成の除外、古い指定の案内、選択範囲、失敗時の保持、画素量上限、リセット・新画像時のWorker終了も確認。
- 別実装psd-tools 1.24.0でも自作画像の出力を読み、日本語名、位置、生RGBA、合成画像の読み込みを確認。旧1.10.9は環境のPillow 12で合成画像の読み込みAPIが合わず、1.24.0へ更新して解消。検証用の任意ツールで、アプリ・サーバー依存には追加しない。
- 本番ビルドとビルド済み画面でもPSDを保存し、Workerの読込・日本語名・サイズ・半透明を検証。通常のnpm ciによる依存再導入とサーバーテスト11件も成功。スマホ幅390pxとPC幅1440pxで横はみ出しなし。
- Photoshop、CLIP STUDIO、Krita、Cubismの実読み込み・実機iPhone/Android/Safari/Windows・ICC変換・最大画像メモリは未検証。独立したPSD読取成功とこれらの対応保証を区別する。

次は画像編集ソフトとCubismに実際に取り込む手順・確認票を準備し、オーナーの利用環境で色・順序・輪郭を検証する。生成補完、動作付け、mainマージ、公開は別承認。
