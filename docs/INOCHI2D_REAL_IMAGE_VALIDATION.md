## 環境の復元

Gitの指定ブランチ/HEADとGitHubの一致、未コミット変更なしを確認。Python3.12.14、Node24.19.0、既存venvとモデルを再利用し、`pip check`と検出/背景除去モデルのSHA検証に成功。生成中にモデルをダウンロードしたり、画像を第三者APIへ送ったりしていない。

公式Creator Linux0.8.6のZIP/Binary SHAは[再現手順](INOCHI2D_CREATOR_CHECK.md)と一致。Xvfb`:94`/1280×960、Mesaソフトウェア描画、通常の起動設定、別のD-Busセッションを使用。Creatorの実行ファイル/SDK/シェーダーは未改変。Windowsや実機スマホの試験ではない。

再起動したサーバーはVite5173とFastAPI8000。GET`/api/inochi2d/status`のconfigured:trueを確認し、実ブラウザから実画像を送信した。API応答のモデルSHAはローカルworkerで別に生成した結果と一致した。通信代替や顔検出の注入を使わない成功例である。

## 画像準備側で修正したこと

変更は`server/inochi_preparation.py`に限定し、旧`model.mjs`/`generate.mjs`は変更していない。

1. 最初の自動生成自体は成功したが、目の明るい境界が眉/髪へつながり、目の範囲が大きくなった。濃いまつ毛/瞳の領域を使い、周辺余白を減らした。
2. 矩形の全域を肌補完すると、髪や眉の角まで消え、紫色のぼけが大きく出た。瞳の色成分と目の形、元まつ毛から非矩形の所有maskを作り、目以外の角は下地側へ残す。細い下まつ毛/明るい虹彩も補完範囲へ含める。
3. 元のまつ毛を列ごとにコピーした閉眼には途切れがあった。元のまつ毛の色・厚み・曲率を測り、連続した曲線として推定する。元の証拠が不足する場合は拒否し、固定素材や透明画像で代替しない。
4. 濃い上まつ毛だけのbbox中心が瞳より上へ偏る場合は、検出した虹彩の中心からPNG範囲を上下へ整える。旧生成器の縮み中心と閉眼線を合わせるための自動計算で、画像固有の手入力座標は使わない。
5. PNGの見える元RGB/alphaを保ち、透明箇所のRGBを0にする。通常合成のRGBAと抽出前景の完全一致を必須とする。元画像の目が半透明なら引き続き拒否する。

青紫の虹彩を持つ今回画像で改善を確認した。別の目の色、小さな顔、暗い髪、隠れた目、反射や特殊な画風での成功率は未測定。局所補完はOpenCV Telea、閉眼は元画像由来の推定で、生成AIによる隠れた構造の復元ではない。

## 再実行用のGUIスクリプト

`scripts/inochi2d/verify-creator.py`を追加。X11/ImageMagick`import`/xdotool/tesseract/OpenCV/Pillowが必要。1280×960、英語の既定Nodes/Parameters配置と3パラメーターに限定した診断で、汎用のCIテストではない。

実行例（生成モデルを公式Creatorで開き、通常の寄付案内のカウントダウン後に閉じておく）:

```sh
.venv/bin/python scripts/inochi2d/verify-creator.py \
  --source /path/to/character.jpg \
  --manifest /tmp/character/manifest.json \
  --model /tmp/character/runtime-input.inp \
  --output /tmp/creator-before \
  --xdotool /path/to/xdotool
```

保存後の新プロセスでは`--model`を保存INXへ、`--output`を新規の別フォルダーへ変え、`--compare /tmp/creator-before`を追加する。スクリーンサイズ/画像照合/表示値/片側独立/復帰/保存前後の差を検査し、不一致なら停止する。結果と画像はGit外へ出す。

## テストと成果物

- Node43件、Python37件、ブラウザ140件、本番ビルド成功。追加2件は明るい眉/髪の混入回避と連続した閉眼線。元の矩形切り出し専用assertは、mask内の元画素保持＋保存PNGからの独立した全体再構成へ更新した。
- 実画像ブラウザ一連処理1回と、公式Creator24状態（保存前12＋新プロセス12）は上記の追加実証。通常のブラウザ140件には通信代替も含まれる。
- 生成器の`officialCreatorTested:false`等は、全出力を一律に検証済みとしないため変更しない。今回モデルのSHAに対応する外部検証記録を別に付ける。
- 私用成果物:`/tmp/inochi2d-maid-trial/`。`final/`にモデルと5PNG、`browser/`に実画面のZIP/記録、`creator-before/`と`creator-after-verified/`に公式の全スクリーンショット/接写一覧/JSON。画像/モデル/Creator本体をGitHubには保存しない。
- ダウンロード用ZIPには生成INP/INX、Creator保存済みINX、5PNG/manifest、比較と公式スクリーンショット、レポートを含める。元JPEG・Creator本体・SDK・ブラウザWASMは含めない。作業再開ZIPやCubism/VTube Studio用モデルとは異なる。
