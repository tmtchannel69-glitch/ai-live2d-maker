# 表情素材の9点変形・開閉の形

## 今回できること

追加PNG一枚を3×3の9点・8枚の三角形で変形する独自プレビュー。素材ごとに閉じた形（0）と開いた形（1）を持ち、左目・右目・口のどれか一つの開きに結び付ける。0〜1の途中は点の位置を直線的に補間する。Live2D/Cubism用のモデルデータではない。

## 操作

1. 元画像と表情素材を読み込み、位置合わせを行う。
2. 「表情素材の重なり・開閉の試作」の「調整する素材」で対象を選ぶ。
3. 「選択した素材の形を編集」で動きに使う値、閉じた形/開いた形、編集する点を選ぶ。
4. 横・縦位置を割合で入力して「この点と開閉の形を反映」を押す。左上は0%、右下は100%。範囲は−50〜150%。点は左上から行順の9点。
5. 反映時に表示条件は「常に表示」になり、編集した形の開き値にスライダーが移る。順序と表示対象は保持する。必要なら後から表示条件を変更できるが、条件次第で途中から素材が消える。
6. 「選択素材の点と線を表示」で反映済みの点を確認する。入力途中の未反映値はプレビューに表示しない。0、0.5、1をスライダーで確認する。
7. 「選択中の形を元の形に戻す」は現在のキーだけを元の矩形に戻して反映する。「この素材の変形を解除」は変形だけを外す。表示設定や画像は残る。
8. 作業ファイルを保存し、再読込して設定と動きを確認する。

未設定時の仮の形は、開く＝元の矩形、閉じる＝中央の高さ10%に縮めた矩形。これは操作の入口で、自然な瞬き・口を自動で作る設定ではない。自動再生は変形ありの場合、左右の目は少しずらした4秒周期、口は2秒周期で滑らかなテスト値を使う。最大約30fpsで描画し、変形なしの場合は従来の二状態切替を維持する。停止時は手動値に戻る。保存・処理・素材変更・ページ非表示時に停止する。カメラ・顔追跡・音声は使わない。

## 保存と検証

作業ファイル版7の `expressionDeforms` に、画像が存在する役割だけを保存する。

```
role: { driver: 'left' | 'right' | 'mouth', closed: [[x,y], ...9点], open: [[x,y], ...9点] }
```

画像と配置、表示設定は従来の項目。版1〜6は変形設定なしとして読める。設定がなければ従来の版で保存する。版6以前に版7専用の項目が混ざったデータを拒否する。旧アプリでは版7を開けない。

固定のキー・役割・点数・有限の座標と範囲を検証する。各三角形の符号付き面積を開閉の両端と途中の最小値で調べ、反転・面積がほぼゼロになる設定を拒否する。エラーで反映済み設定や作業を失わない。素材を外したときはその変形設定も外し、同じ役割の素材を置き換えた場合は保持するため、新しい素材に合うか再確認する。

## 制限と次の工程

- 点は数値編集に加え、専用画面で指・マウスのドラッグが可能。拡大・移動・矢印の微調整、最大30操作の取り消し・やり直しを用意。確定前の下書きは閉じると破棄し、操作履歴は作業ZIPに含めない。[スマホでの編集](MOBILE_UX.md)。
- 一つの素材に一つの開閉値。口の形、顔の向き、複数値の組み合わせ、親子変形は未対応。
- 三角形ごとのCanvas描画なので境界に細い筋が出る場合がある。透明素材や実キャラクターでの品質・実機スマホ性能は未評価。
- 目や口の内部だけに描くマスク処理は未対応。元画像を背景にすると既存の目・口が残る。下地・まぶた・唇・口内部等の準備と重なり調整が必要。
- 変形は作業ZIPとプレビュー専用。元PNG・制作素材ZIP・PSDは変更しない。
- moc3出力、VTube Studioでの実読み込みは未実現。Cubismなしで対応モデルを書き出せることを保証しない。[モデル制作方針](MODEL_AUTHORING.md)。
