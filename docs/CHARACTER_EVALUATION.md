# 提供されたキャラクター画像の評価

2026-10-09（日本時間）。ユーザーが評価依頼に応じて提供した一枚を、自前 CPU 環境だけで処理した。
第三者 AI サービスへの送信、画像・派生 PNG の GitHub 保存、公開、課金は行っていない。

## 条件
- 入力: 853 × 1280 px の JPG、一枚。元の寸法を保持した透明 PNG を出力。
- SAM 2.1 tiny、CPU 4 スレッド。モデル・ソースの固定条件は AI_PROTOTYPE_RESULTS.md と同じ。
- 点指定で 4 パーツ、枠指定で 4 パーツをそれぞれ一回処理。
- 点の画素座標: 髪 (417,65)、顔 (430,188)、目 (394,152)、衣装 (427,352)。
- 枠 [左,上,右,下]: 髪 [145,8,700,730]、顔 [355,125,488,218]、目 [370,134,484,171]、衣装 [175,245,657,650]。
- 見た目の確認は、生成 PNG をブラウザで市松模様に重ねて行った。比較表示では透明余白を省いて拡大したが、出力 PNG 自体は元画像サイズ。
- 正解マスクの作成は未実施。重なり率などの精度数値は算出していない。

## SAM の結果

| 対象 | 点指定の目視結果 | 枠指定の目視結果 | 判断 |
|---|---|---|---|
| 髪 | 頭頂・前髪・顔の横の髪を抽出。下方へ伸びる長い髪は不足。髪飾りも混在 | 長い髪の範囲を含むが、袖等の衣装と顔の一部が混在 | 一点・一枠だけでは制作素材として不十分 |
| 顔 | 顔の主要部分を抽出。額付近が途切れ、小さな不要領域が残る | 点指定より広い額の範囲を抽出するが、境界の確認・修正が必要 | 補助結果として利用可能。完成レイヤーではない |
| 目 | 一方を指定して両目の領域が抽出された。輪郭と左右の独立性は要確認 | 両目に加えて眉周辺・鼻や肌の領域が混ざる | 点指定が有望だが一例で一般化できない |
| 体・衣装 | 黒いトップスだけを抽出。ジャケット・スカート・手足は含まない | 主にジャケットの左右を抽出。トップス・スカート等は不足 | 「体・衣装」の一項目では対象が曖昧。分ける仕様案が必要 |

点指定一回（全 4 領域）: 4.487 秒。モデルの初回読込を含む。
枠指定一回（全 4 領域）: 1.975 秒。起動後の実行。
一回ずつの測定であり、平均・上限・再現性の保証ではない。

## 背景除去の補助評価
BiRefNet-general-lite を同じ画像で一回実行。推論 7.185 秒、出力 853 × 1280 px。全身と長い髪の主な輪郭を保持し、白背景を透明化できた。細い髪や半透明の縁の厳密な品質は未採点。キャラクター全体の背景除去であり、髪・顔・衣装の分離ではない。アプリ画面への背景除去接続は未実装。
