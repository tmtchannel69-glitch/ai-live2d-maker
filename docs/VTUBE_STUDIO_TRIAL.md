# Windowsで生成モデルを試す

2026-10-21。生成済みモデルをWindowsのVTube Studioで確認するための手順です。モデルを試すためにCubism Editorを入れる必要はありません。VTube Studioが利用できる状態になってから実施します。導入済みとは確認できておらず、この作業でSteamの契約・導入・ログインは行っていません。

現在、実画像から作ったモデルの整合性、瞬き・口の開閉、描画画素の変化は独立実装のPurismCoreで確認しています。**公式Cubism CoreとVTube Studioでの実読込・追跡は未確認**です。以下は公開資料を確認して用意した手順であり、Windowsで実行済みという記録ではありません。

## モデルを入れる

1. アプリの「Live2Dモデルを生成する（実験）」で保存したモデルZIPをWindowsへ用意します。作業再開用ZIP・制作引き継ぎZIP・PSDはVTube Studioのモデルとして開けません。
2. ZIPを展開し、`*.model3.json`、同じモデルの`*.moc3`、テクスチャのフォルダーを確認します。中の名前・階層・参照関係を変えず、**モデル一式を一つのフォルダーへまとめます**。

   ```text
   ai_live2d_trial_20261021/
     character.model3.json
     character.moc3
     character.1024/
       texture_00.png
     AI_LIVE2D_BUILD_REPORT.json
     …ほかの生成ファイル
   ```

   名前や画像の枚数は例です。実際のZIPをそのまま使います。外側のフォルダー名は自由ですが、中のファイル名やテクスチャのフォルダー名を変更すると参照が切れます。`*.cdi3.json`はVTube Studioでは必須ではありません。`*.physics3.json`がない場合、物理による髪の揺れまで用意できたとは扱いません。
3. VTube Studioのモデル設定にあるデータフォルダーを開く操作から、`Live2DModels`フォルダーを開きます。Steamのインストール場所を推測して固定パスへコピーする必要はありません。
4. その中へ上のフォルダーを丸ごとコピーします。同名の試作があれば、既存のモデルや設定を上書きせず、外側だけ別名のフォルダーにします。ZIPそのものを置いたり、`model3.json`だけをコピーしたりしないでください。
5. VTube Studioを再起動し、モデル一覧から試作を選びます。初回はAuto-Setupを実行します。VTube Studioが作る`*.vtube.json`は同じモデルフォルダーに残します。新しい試作に古い設定をコピーするのは、最初の確認が終わってからにします。

## 順番に確認する

最初にモデルを開き、正面・両目が開いた状態の顔、前髪、首、衣装と透明背景を確認します。次にカメラ等の追跡を有効にし、下表を一項目ずつ試します。自動瞬き・表情・待機アニメーションが結果へ影響する場合は、その設定を控え、必要に応じて一時的に止めて切り分けます。

| 順序 | 操作 | 見るところ |
|---|---|---|
| 1 | 両目を開き、口を閉じて正面を見る | 元の目・口の二重表示、開口の残り、顔と髪の重なり |
| 2 | 片目だけを閉じ、ゆっくり開く。反対側も同様 | 左右それぞれの閉/途中/開、閉眼時に瞳が残らないか。自分のどちらの目で、どちらのモデルの目が動いたかも記録 |
| 3 | 両目を閉じて開く | 左右のずれ、ちらつき、半開きの形 |
| 4 | 目は開いたまま、口を閉→半開→開→閉 | 閉口線と口内部の二重表示、閉じても開口が残らないか、歯や唇のはみ出し |
| 5 | 瞬きと口を組み合わせ、顔を少しずつ左右・上下・傾きへ動かす | 追跡への反応、首・額・髪際の隙間、破れ、遅れ |

左右の素材名はキャラクター本人の左右で、正面の左目は画面右です。今回の顔の向きの見た目は品質判断を保留しています。向きが反応しても自然な立体表現の完成とはせず、気になる角度と隙間を記録してください。

Auto-Setupで動かない場合はモデル設定の入力→出力の対応を確認します。標準IDは推奨であり、名前や範囲が違うモデルでも手動で対応付けられます。

| VTube Studioの入力 | モデル側の標準ID |
|---|---|
| `EyeOpenLeft` / `EyeOpenRight` | `ParamEyeLOpen` / `ParamEyeROpen` |
| `MouthOpen` | `ParamMouthOpenY` |
| `FaceAngleX` / `FaceAngleY` / `FaceAngleZ` | `ParamAngleX` / `ParamAngleY` / `ParamAngleZ` |

目と口は通常0〜1ですが、実際の出力範囲はモデル設定・生成レポートで確認します。入力値が動くのにモデルが動かない場合は、出力先ID、表情・アニメーション・物理設定による上書きも確認します。

## 開けない・動かない場合に残す情報

まずモデル一覧へ出ない、開くとエラー、画像が欠ける、追跡入力が動かない、入力は動くがモデルが動かない、のどれかを区別します。次を記録してください。

- WindowsとVTube Studioのバージョン、追跡方法（Webカメラ・スマホ等）、試した順序と再現する操作。
- 展開したフォルダー構成と`model3.json`のファイル名、ZIP内の`AI_LIVE2D_BUILD_REPORT.json`。モデルを作り直した場合は、どの出力か識別できるようにします。
- エラーの発生時刻と該当ログの抜粋。VTube Studioのメインメニューの「Log」から確認でき、全文は`Live2DModels`の隣の`Logs`フォルダーにあります。ユーザー名や個人のパスは伏せます。
- 表示の問題は、正面/左目/右目/口/向きのどの状態で起きたか。画像やモデルを公開する必要はありません。

読み込めたこと、各部位が追跡で動いたこと、見た目が自然なことは別に記録します。独立ランタイムの検証結果をVTube Studioで確認済みへ書き換えず、実機で行った結果を別の確認記録として残します。今回のGPL生成ツールはローカル検証用で未配布であり、この手順で公式互換や公開・配布の承認を得たことにはなりません。
