# STEP 3：小さい毛束変形と公式物理の設計

2026-10-24。STEP 2の結果確認後、オーナー承認の範囲で追加。[頭/首/胴体](HEAD_RIG_DESIGN.md)、[再生成](REPRODUCING_CHARACTER_RIG.md)。

## 変更する経路

`scripts/parts/rig.py --stage hair`は従来の画像準備と共通パーツを再利用し、頭部版を生成した後、`hair-rig.mjs`へ渡す。既定の`--stage head`、安定5役割、旧詳細/品質版、worker/API/UIを切り替えない。`head-rig.mjs`への変更はbuilderの注入とコンテナ梱包関数の公開だけで、既定の頭部モデルSHAが変わらないことを確認する。

- `hair/`：毛束ごとの独立パラメータを持つ小さい変形のモデル。
- `hair-physics/`：同じ変形へ公式0.8.6のSimplePhysicsを接続したモデル。driverのファイル生成と公式の実動作は別判定。

## 観測と推定

既存の9毛束候補に、観測断片の上側から推定した`root_xy`を使う。頭皮の根元を復元したとは扱わない。髪飾りや根拠のない候補を新しく髪へ塗り替えず、元の4つの粗い髪領域は頭へ追従するだけにする。

構造はHead→HairRoot→観測Part/別補完Part、物理版のみ同じHairRootにdriver。観測Partは13×25、下地は9×17の格子で、根元では変形0、下側へ滑らかに増やす。既存の狭い補完量から先端移動を上限1.75px、角度を上限.006radへ制限する。

補完は元の観測PNGとは別にし、元のRGBAを変更しない。中立では公式SDKのDodgeMaskで現在の観測に隠す。顔/首/衣装も被覆者に含め、動いた際の狭い露出だけを埋める。alpha254を255へ変えず、250未満の縁へ下地を重ねない。複数の目の観測役割は出力側で対応する頭部Partへ解決する。

髪のfront/side/backの順序は位置からの推定。真の重なりや根元、衝突は未確認。髪の境界が公式画面で前段と完全一致しないことも、CPUの中立RGBA一致とは別に記録する。

## 物理と検証

JSONに保存するenumの表記は`model_type: "Pendulum"`、`map_mode: "AngleLength"`。SDK内の下位文字列値とは異なり、公式0.8.6が使うFghjはDのメンバー名を読む。初回の小文字出力は公式で明示的に拒否されたため不採用にし、この変換を独立した髪出力だけで修正した。

固定SDK v0.8.6の`SimplePhysics`、`pendulum`、`angle_length`を使用。観測長から40〜600pxの振り子長、重力1、角度減衰.45、長さ減衰.6、出力scale[40,0]を設定する。既存のHeadX/HeadTilt/まばたきと首の変形は維持。生の物理出力はSDKがパラメータ範囲へ写像/制限してから、小さい変形へ接続する。

- `render-hair.py`：実モデルの独立診断。各毛束±1、同時、頭との組み合わせ、閉眼、復帰の25状態で、中立差/内部の穴/胴体の変化を記録。
- `verify-creator.py`：従来の26状態。スクロールバー幅と入力保持時間を指定可能にし、表示値の許容誤差は維持。
- `verify-hair-creator.py` / `creator_ui.py`：公式の検索欄と表示された名前/値を照合し、各毛束±1/0の27操作と復帰を撮影。ソフトウェア描画時のSDL入力取りこぼしには各キーを保持して対応。入力失敗を生成/互換成功と扱わない。
- `verify-hair-physics.py`：公式GUIでHeadX移動後、表示された9パラメータと画面を実時刻付きで記録。Pythonで物理を代替せず、固定fpsも仮定しない。停止、正負の揺れ戻し、減衰、胴体固定を判定。保存したモデルは新しい公式プロセスで再検証する。
- `check-rig-retention.py`：保存後の親子/mesh/マスク/パラメータに加え、driverの接続先、長さ、減衰、方式を検査。UUIDは名前へ解決し、接続先消失を拒否。
- `rig-fixture.mjs` / `hair-test.mjs`：外部素材なしで原データの不変、根元固定、変形mesh、既存bindings、物理参照、不正根元/候補なしの拒否を検査。

結果は[検証記録](HAIR_RIG_VALIDATION.md)へ保存する。モデル/画像/画面写真はGit外、GitHubにはコード・設定・画像なしの測定値だけを保存する。Inochi2D旧INP/INXの試験であり、Cubism/VTube Studio/INP2対応ではない。
