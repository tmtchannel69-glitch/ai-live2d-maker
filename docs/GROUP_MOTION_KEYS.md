# グループの左・中央・右の動き

2026-10-11。包括承認内の通常開発として、独自Canvasプレビューに3位置の動きを実装。顔の立体変形・顔追跡・Live2D互換モデル出力ではない。

## 操作

1. 表情素材を読み込み、「素材をまとめて動かす」で所属を設定する。顔全体の対象には子の目・口も含む。
2. 「スライダーで動く位置を設定」でグループと左（−1）・中央（0）・右（1）を選ぶ。
3. 「この位置の動きを編集」で対象位置の合成を見ながら指で移動・回転・比率を保った拡縮・中心点変更を行う。既存の拡大・画面移動・矢印・数値・最大30操作の取り消しを使える。数値は先に「数値を下書きに反映」を押す。
4. 「この位置の動きを確定」でその位置だけを反映。初回は未編集の2位置を通常のグループ配置から用意する。閉じる・変更せず戻る・Escapeは全キーを保持する。編集対象のグループと所属はこの画面では変更しない。
5. 「顔の向きの試作」スライダーで位置の間を確認する。「向きと表情の動きを再生」で瞬き・口・向きの動きをまとめて試す。

専用画面の「このグループを元に戻す」は編集中の1位置を通常の配置へ戻し、専用画面内で取り消せる。「通常の配置から3位置を作る」は3位置すべてを現在の通常配置へ置き換える。「このグループの動きを解除」は3位置を外し、保持されている通常の配置に戻す。

## 通常配置と動きの関係

キーの移動・回転・中心・倍率は通常の配置に足す差分ではなく、そのグループの変換全体。設定済みのグループは3位置の補間値で通常の変換を置き換える。通常配置の編集は保存されるが、既存の3位置は自動で変更しない。通常の所属・範囲追従は共通で、キーごとに変えない。

左→中央と中央→右の各区間で全6項目を直線補間する。角度も数値の間を直線でつなぎ、180度の境界を自動で回り込まない。親子はそれぞれ補間してから実ピクセル上の行列を合成する。未設定のグループは通常配置を維持する。共通の向き値1本を使い、各グループ独立の値や複数の値を掛け合わせる操作は未対応。

表示範囲の追従ありは素材と同じ補間済みの親子行列を使い、固定の範囲は元画像上に残る。範囲編集の枠と指の座標も現在の補間済み行列を使う。開閉に合わせた範囲の変形は未対応。9点変形・表示条件・重なり順は既存のまま併用できる。

再生中は手動スライダーとキー編集を禁止する。保存・素材変更・別処理・ページ非表示で停止する。止めると手動スライダーの位置へ戻る。元画像・元PNG・素材ごとの配置・制作素材ZIP・PSDは変えない。

## 作業ファイル版10

設定ありでは版10の `groupMotionKeys` に、グループIDから `negative` / `center` / `positive` の3変換を保存する。各変換は `dx`, `dy`, `pivotX`, `pivotY`, `angle`, `scale` の全6数値。通常の `expressionGroups` とは分ける。値の制限は通常グループと同じで、移動±100%、中心0〜100%、角度±180度、倍率10〜400%。

未知のグループ、対象素材なし、不足/余分な位置・項目、文字列・非有限/範囲外の数値・ゼロ倍率を拒否し、現在の作業を保持する。版1〜9はキーなしで開き、版9に新しい項目を混ぜたファイルは拒否する。以前のアプリは版10を開けない。

解除後は残った設定に応じた版で保存する。対象素材を全部削除・所属解除したグループのキーを外し、通常の変換は保持する。素材置換ではキーを保持。新画像・リセットは全キーを整理する。手動スライダーの値、再生状態、下書き・履歴は保存せず、読込は中央から始まる。

サンプルは自作図形から顔と11素材、顔の左/中央/右の移動・傾き、開閉・範囲設定を生成し、版10で保存・再開できる。AI・外部画像・画像送信・モデル生成は使わない。実機と実キャラクターの自然な動き、moc3/VTube Studio出力は未検証/未実現。
