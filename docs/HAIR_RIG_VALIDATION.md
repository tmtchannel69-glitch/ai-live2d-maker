## 既知の問題

CPUの中立RGBA一致とは別に、公式画面では頭部版との髪境界に差がある。同じviewportの比較で差のある画素88,210、そのうちRGB差3超16,943、最大175。多くが髪の細い境界で、階層/重ね順とテクスチャのフィルタリングを精査する必要がある。頭を移動した際には髪/衣装の補完境界にギザつきも見える。元の外見の完全再現や自然な動作の合格とはしない。まばたきの推定肌のぼけ/境界も残る。

初回の髪下地は髪同士の被覆だけを参照したため、CPUの内部の穴候補49で不採用。顔/首/衣装の現在の観測も被覆者へ含めると最終25状態で0になった。公式の27操作でも、明るい内部415,455画素を補助検査し、背景色に近い穴候補0。ただし輪郭付近/暗い領域/色の誤りや自然さを保証する検査ではない。

物理版の小文字enumは公式で`Unable to deserialize string 'pendulum' to PhysicsModel`となり、不採用。FghjのDメンバー名`Pendulum`/`AngleLength`へ直し、独立した物理版だけを再生成した。旧版のモデル/ログは失敗例として私用領域に保持する。GUIの操作不成立も検出して停止し、これをモデルの実動作成功として数えない。

頭の移動と平面Z傾き以外の顔X/Y角度、隠れた本来の構造、真の毛束根元/奥行き/衝突、大きな揺れ、別画像での一般精度、Windows/iPhone実機、通常スマホ画面への詳細CLI接続は未完了。Inoxの0値/透明度は別課題のまま。
