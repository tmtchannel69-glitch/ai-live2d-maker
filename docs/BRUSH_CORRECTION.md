# ブラシ補正と確認記録

## 承認と実装範囲
オーナーの「続けて」により、既存四分類の AI 結果に対するブラシ補正を実装。画像の色を新しく生成せず、元画像の色を使って透明度を変更する。15 分類、PSD、隠れ部分の生成、永続保存は今回の対象外。

- 結果カードから補正画面を開き、消す / 元画像から戻す、太さ 1〜200 px、100 / 200 / 400% 拡大、拡大画面の移動、数値で点を置く操作ができる。
- 補正前は画面を開いた時点の結果。元画像の薄い重ね表示は確認専用で書き出さない。
- 反映前の操作は作業中の領域に留め、閉じる・Escape で破棄。反映時に一パーツだけ Blob とプレビューを置き換える。他のパーツと、エラー時の旧結果は保持する。
- 元サイズ・位置を維持。元画像の半透明度を二重に掛けないよう、初期マスクの透明度を元画像との比率に正規化する。戻す操作で元画像の透明度を維持し、完全透明な部分は戻せない。
- 履歴は変更した 64 px のタイルの透明度のみ保存。最大 100 操作 / 透明度データ 32 MiB。古い履歴を整理した後でも、その補正は保持。履歴は画面を閉じると解放する。一つの長いストロークは 4096 点で区切り、案内する。
- リセット・再選択・AI 再分離時は補正画面を閉じる。画像読み込み・PNG 生成の遅い完了が新しい結果を上書きしないよう、画面の世代と結果の同一性を確認する。

## 検証
- ブラウザ合計 16 件成功（実 SAM 一件を含む）。サーバー既存 10 件成功。本番ビルド成功。
- 新規四件は AI API を代替し、透明領域の復元、元の RGB、半透明、完全透明な入力、補正前の比較、確認用重ね表示、PNG のサイズ・画素、ZIP の更新内容、他パーツの維持を検証。
- 拡大した画面でブラシ位置を確認。Chromium のタッチ入力で「画面を移動」の横スクロールを確認。操作途中のキャンセル、未反映変更の破棄、保存失敗時の旧結果と下書き維持、閉じた後の遅い PNG 応答の破棄、古い取り消し履歴を整理した後の補正保持も確認。
- 実 SAM の既存テストは実推論と PNG の透明度を確認。新しいブラシテストとは分けて実行。
- 提供画像の以前の実 SAM 髪マスクをブラウザへ読み込み、消す・戻す・反映を確認。保存は 853×1280、(250,300) の透明度 0、(280,450) の透明度 255 を確認。補正の動作確認用で、髪の輪郭を仕上げた品質評価ではない。この確認では API 応答のみ既存マスクで代替し、モデルは再実行していない。画像と派生画像は /tmp のみ、GitHub に含めない。

## 制限と次の作業
スマホ幅 390 px の Chromium とデスクトップの既存テストで確認。実機 iPhone / Android / Safari、最大画像での端末メモリ、ペン圧・ピンチ拡大は未検証。大きな画像では複数キャンバスと画像データを保持するため、履歴の上限だけでメモリ安全を保証しない。

補正は画面内の作業で、ページ更新後には残らない。次は端末へ作業ファイルを保存し、読み込みで元画像・指定・結果を再開できる機能を提案する。保存データの仕様と扱いは承認後に実装する。
