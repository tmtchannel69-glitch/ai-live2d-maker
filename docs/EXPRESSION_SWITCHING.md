# 表情素材の重なりと開閉の試作

2026-10-09。最新の「続けて」で、読み込んだ追加素材の合成、重なり順と表示条件、画像切り替えによる開閉の試作、設定の保存を実装。

## 操作と表示

1. 「表情素材の読み込み・位置合わせ」で必要なPNGを読み込み、元画像に対する配置を設定する。
2. 「表情素材の重なり・開閉の試作」で追加素材を合成する。初期背景は透明。元画像の背景は位置確認用に選べるが、既存の目・口の絵は残る。
3. 左目・右目・口のスライダーを動かす。0.5未満は閉じた状態、0.5以上は開いた状態として、条件に合う素材だけを表示する。
4. 調整する素材を選び、重なり順、表示条件、表示対象かどうかを設定し「表示設定を反映」を押す。順序は0〜99で大きいほど手前。同じ順序は役割定義の順で描画する。
5. 「瞬き・口の切替を再生」で固定タイミングのテストを行う。左目は4秒ごとの終わりの0.4秒、右目は少しずらした0.4秒の閉じた表示。口は1秒ごとに開閉する。再生を止めると手動のスライダーの状態へ戻る。撮影・音声・顔追跡は使わない。

素材や配置の変更、表示設定の反映、他の処理・保存開始、元画像の変更・リセット、ページが非表示になった際は再生を止める。作業の復元時は自動再生せず、目の開き1・口の開き0へ戻る。再生中のスライダー操作は無効にする。動きを減らす端末でも、自動再生せずボタンを押した場合だけ再生する。

## 初期設定

| 役割 | 表示条件 | 順序 |
|---|---|---:|
| 下地の肌 | 常に表示 | 0 |
| 左右の白目 | それぞれの目が開いている | 10 |
| 左右の瞳 | それぞれの目が開いている | 15 |
| 左右のまつげ・まぶた | それぞれの目が開いている | 20 |
| 左右の閉じた目 | それぞれの目が閉じている | 25 |
| 口の内部 | 口が開いている | 5 |
| 歯・舌 | 口が開いている | 15 |
| 上唇・下唇 | 常に表示 | 15 |
| 閉じた口 | 口が閉じている | 20 |

仮の初期値であり、素材に合わせて調整する。別の表示条件へ変更も可能。読込時点でこれらの初期設定を作業ファイルに自動追加せず、設定を反映した役割だけ記録する。

## 保存と互換性

表示条件・順序・対象の設定がある場合は作業ファイル版6。画像と配置は従来のexpressions、表示設定はexpressionLayersの役割別辞書として保存する。再生状態、スライダーの値、背景は保存しない。設定がなければ素材ありは版5、その他は従来の版を維持する。旧版1〜5は読み込める。以前のアプリは版6を開けない。

未知の役割・条件、画像がない役割、整数以外や範囲外の順序、真偽値以外の表示対象、余分なキーは拒否し、作業を保持する。素材を取り外すと、その役割の表示設定も外す。素材の置換では設定を維持する。準備一覧のテキストには順序・条件・表示対象も追加する。

元画像・既存のAI結果・追加PNGを変形せず、PNG・ZIP・PSDには本表示設定を含めない。画像と設定はブラウザ内で処理して端末の作業ファイルへ保存し、外部送信先や新しい依存は追加しない。

## 限界と次の工程

本試作は追加素材だけを描く二状態の画像切り替え。滑らかな瞬き、口の形の補間、メッシュ・クリッピング・親子変形、頭の向きとの連動、Live2Dモデル出力はない。中間値0.1と0.4の形は同じ。開いた状態と閉じた状態に必要な素材がないと、部品が消えたり元の絵が残るため、見た目を手動確認する。

既存のAIパーツの頭・髪の試作とは別のプレビュー。VTube Studioへこの設定を読み込むことはできない。moc3の作成経路は引き続き未確定。

次は、各部品の形の変化を編集するキーとメッシュ、見える範囲・親子関係を設計・試作し、二状態の切り替えから形の変化へ進める。元画像にない形の生成・新しいサービス・SDK契約・費用・公開は今回実施しない。

## 構造と検証

`src/expression-layer-state.js`に初期設定・検証・条件判定、`src/expression-scene.js`に独自合成と再生、`src/project-file.js`に版6を実装。合成用の元画像は最大640×960、追加素材は各320×480以内に縮小して保持。入力デコードは一枚ずつ進め、遅い処理を世代番号で破棄し古いビットマップを閉じる。再生中は状態が切り替わる時だけCanvasを再描画する。元画像の初回デコードや複数画面の同時読込の負荷は残り、実機スマートフォンの性能は未評価。

自作図形で実画素の左右別切替・口の切替・0.5境界・重なり順・非表示、元PNG維持、版6保存復元、不正設定拒否、版5互換、素材取り外し時の設定整理、再生停止、遅い合成の破棄をブラウザテストする。実キャラクターの自然な表情やCubism/VTube Studioの実読込を検証したとは扱わない。
