# 確認記録付きの制作素材ZIP

最新の「続けて」を、確認記録と不足一覧を添えた制作素材ZIPの実装承認として扱う。処理はブラウザ内、追加ライブラリや外部送信なし。元画像・ユーザーの出力ファイルはGitHubへ保存しない。

## 保存対象と使い方
「確認記録付き 制作素材ZIP」でai-live2d-materials.zipをダウンロードする。表示中の構成の選択項目だけが対象。生成済みの未選択パーツ・別構成の結果は除外し、選択項目の結果なしも一覧に残す。選択ゼロと画像なしでは利用できない。結果がゼロでも確認一覧のみのZIPを保存できる。

| ファイル | 内容 |
|---|---|
| CHECKLIST.txt | 日本語の集計・パーツごとの境界と描き足しの記録・不足事項・メモ |
| README.txt | 保存内容、左右、AI素材の位置、デモの制限、後続の制作と作業再開方法 |
| manifest.json | format=ai-live2d-maker-materials、version=1の情報 |
| parts/id.png | 選択項目のうち結果があるPNGを加工せず保存 |

テキストはWindowsのエディターでも日本語を認識しやすいUTF-8 BOMと改行CRLF。JSONは標準のUTF-8。メモはプレーンテキストとJSONだけで、HTMLやCSVではない。

PNGだけの「まとめて ZIP 保存」は従来どおり表示中の全結果を保存する。制作素材ZIPとは選択範囲も異なる。作業再開は「作業ファイルを保存」のai-live2d-work.zipを使う。制作素材ZIPを作業ファイルとして開いても復元できず、現在の作業は保持する。

## 情報の意味
manifestに構成・方式・元画像キャンバスの幅と高さ・containsOriginal=false・座標系を保存する。元画像のバイト列とファイル名・点や枠・履歴は含まない。各parts項目はID、表示名、PNGパス（結果なしならnull）、画像サイズ、ai/demo/missing、位置情報、ブラシ補正の有無、現在の指定との一致、確認記録、現在有効な境界状態、不足事項を持つ。

AI結果は元画像と同じサイズで左上原点{x:0,y:0}、alignment=source-canvas。トリミングや再描画をしない。デモはcropped-demo、原点はnullで元画像上の位置を再現できない。メモとPNGは出力に含まれるので、別の人に渡す前に内容を確認する。

不足事項は、結果なし・デモ・指定変更あり・境界未確認・境界修正必要・描き足し未確認・描き足し必要の7種類。選択項目の件数と各状態を集計する。古い指定の結果にchecked記録があってもreviewには記録を保持し、currentBoundaryはuncheckedとして集計する。修正や描き足しは実行しない。記録上の不足事項がゼロでも、素材やモデルの完成を宣言しない。

## エラーと出力中の変更
上限は全体100 MiB、各PNG32 MiB、各辺4096 px・1600万画素。既存の作業ファイルから読み込んだ複数の結果でも、この上限を確認してからZIP化する。AIのキャンバスサイズ一致、PNGヘッダーとサイズ、選択ID・重複・方式・確認記録も確認。PNGは順番に読み込んで保存方式0でZIPへ入れる。

出力中は方式・選択・修正・記録変更と他の保存操作を抑止する。リセットと元画像変更は可能で、遅れて完成した古い出力をダウンロードしない。出力失敗時はPNG・指定・記録を保持し、再実行・個別PNG・作業ファイル保存が可能。

## 制作上の範囲
レイヤー付きPSD、完成したLive2Dモデル、Cubismの変形・動作設定は含まない。隠れ部分の生成や描き足し、目・口の素材細分化も行わない。PNGを画像編集に持ち込み、確認一覧を参照して不足部分を準備するための出力。
