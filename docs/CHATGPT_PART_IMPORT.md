# ChatGPT画像を使う1パーツ取り込み（ローカル試験版）

2026-10-24。一般公開の前段として、ChatGPTなどで作った**独立した透過PNG**を、端末内で既存の33パーツのうち1パーツだけ差し替えて、合成プレビューとInochi2D INP/INXを試す機能を追加。

## iPhoneでの使い方

1. アプリ内の「パーツから生成」を開き、「デザイン指定の端末内描画」を選ぶ。
2. まず「パーツを生成して組み立てる」で、33個の基準パーツとモデルを完成させる。
3. 下に表示される「ChatGPTなどで作った透過PNGを試す」で役割を選ぶ。初期値は本人左の虹彩 `iris_l`。
4. ChatGPT等で**その役割だけ**を描いた背景透過PNGをiPhoneに保存して、ファイルを選択する。通常の全身完成絵をそのまま指定しても、パーツには自動分割されない。
5. 「1パーツを置換してモデルを試す」を押して、配置・透明度を確認し、実験専用プレビューとモデル生成の結果を見る。
6. 「実験結果ZIPを保存」で差し替えた `parts/iris_l.png`、合成 `preview.png`、 `character.inp`、`character.inx`、生成検証記録を保存する。

## ファイル仕様

- 入力は8MB以内の**8bit RGBA透過PNG**のみ。JPG、写真、完成キャラクターの不透明スクリーンショットは取り込めない。
- サイズは選択中のパーツの矩形サイズ（例：虹彩62×74）、768×1024の基準キャンバス、1024×1024のAPIキャンバスのいずれか。
- 768×1024の全体座標画像は、元ブループリントの座標にパーツだけ描く。1024×1024では、全体に対しX+128した位置だけに描く。
- PNGの**範囲外に不透明画素が1つでもあれば拒否**。範囲内に見える画素と透明画素が両方必要。範囲外の塗りを無断で除去したり、別の見た目に加工して成功扱いしない。
- 正規のPNGヘッダーを調べ、ブラウザーで画像をデコードして描画・透過画素を検査。実験側の結果に元画像のSHA-256を記録する。
- 新しい `assets` Mapへ1パーツだけ置換して、既存のプレビュー合成と `buildDesignedInochi` を再利用。
- 差し替え後の結果は実験専用の領域とZIPに隔離。既存の生成物、通常のダウンロードZIP、33パーツのソースデザインは変更しない。

## 実装上の正直な制限

**この機能はChatGPTを自動呼出ししない**。ユーザーが作ったPNGの端末内取り込みだけ。AI出典の真正性は未確認。33パーツのうち1パーツだけ入れ替えるので、AIによる完全なキャラ生成でも、1枚の絵からの全自動パーツ分離でもない。元の32パーツはローカルのSVGテンプレートのまま。

動作モデル自体をInochi2Dフォーマットで再生成するが、公式Creatorで開いて品質を確認するテストは別途必要。CubismやVTube Studio形式ではない。ハイライト・髪などの見た目や欠けた隠れ領域の品質はユーザーによる確認が必要。

画像の外部送信、OpenAI API、APIキー、課金、アカウント登録、mainへの統合、一般公開はこの変更に含まれない。
