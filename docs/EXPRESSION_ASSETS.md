# 表情素材の読み込みと位置合わせ

2026-10-09。オーナーの最新の「続けて」で、用意済みの表情素材の読込・役割・配置・作業保存を実装。AIによる隠れ部分の生成や、動くモデルの出力は今回の対象外。

## 操作

1. 元画像を選び、「表情素材の読み込み・位置合わせ」の素材の役割を選ぶ。
2. 「PNGを読み込む・置き換える」で用意した画像を選ぶ。透明PNGを推奨するが、透明かどうかや絵の内容は自動判定しない。一役割一枚で、成功時にその役割だけ置き換える。失敗時は以前の素材を保持する。
3. 背景を元画像または透明に切り替え、選択した一枚の位置を確認する。座標と大きさを数値で入力して「配置を反映」を押す。
4. 「作業ファイルを保存」で追加画像・役割・配置も保存する。読み込み中は他の処理と作業保存を抑止する。リセット・元画像の再選択は可能で、進行中の読込を中止する。
5. 「この素材の元PNGを保存」で読み込んだ画像をそのまま保存できる。「この役割の素材を外す」は現在の作業からその役割だけ外す。以前に保存した作業ファイルは変更しない。

左・右はキャラクター本人の左右。正面では左が画面右。役割は閉じた目左右、白目左右、瞳左右、まつげ・まぶた左右、目・口の下地の肌、上唇、下唇、口の内部、歯、舌、閉じた口の15種類。

配置は元画像に対する比率で記録。左端X・上端Yは0〜100%、幅・高さは0.01〜100%。元画像の右や下へはみ出した領域はプレビューで切れる。元画像と同じキャンバスの素材は初期位置0/0・大きさ100/100となる。小さく切り抜いた素材は元のピクセルサイズを維持して中央へ置き、元画像より大きい場合は比率を保って収まるサイズに縮める。縦横比を極端にした素材では最小の比率へ丸める場合がある。

数値変更は「配置を反映」するまで保存されない。元画像や別の作業を開くと、その元画像に対応した追加素材へ切り替わる。無効な元画像・作業ファイルは現在の素材を保持する。構成切り替え・再分離・ブラシ補正では追加素材を消さない。

## 表示と出力の範囲

この画面は位置合わせ用。元画像の目や口を消す機能、追加素材の自動生成、複数素材の重ね順・動作設定、メッシュ・変形キーの編集はまだない。選択した一枚だけを表示し、元画像に既に描かれた目や口は背景に残る。

追加素材と配置は既存のAI結果のPNG・ZIP・制作素材ZIP・PSD、動作プレビューにはまだ含めない。「作業ファイル」は画像も含む。「準備一覧」は追加した役割・サイズ・配置と未確認の案内のみを含み、画像や追加素材のファイル名は含まない。読込済みを品質確認済み・表情完成と扱わない。

## 保存と互換性

- 追加素材がある作業ファイルは版5。`expressions/<role>.png`に元のPNGバイト、`project.json`のexpressionsに役割・名前・寸法・配置を保存する。アプリ独自の作業形式で、CubismやVTube Studioのモデル形式ではない。
- 旧版1〜4を読み込める。旧版では追加素材なしに戻す。追加素材なしの保存は従来の版を維持する。以前のアプリは版5を開けない。
- 既知の役割、重複なし、固定の画像パス、有限な配置範囲、画像の寸法一致を検証する。未知項目、パスの変更、欠落や余分な画像、不正PNGは現在の作業を保持して拒否する。
- PNGは各10 MiB以下・各辺4096 px以下・1600万画素以下。ヘッダーの寸法を確認してからデコードする。作業ZIPの展開合計と保存合計は従来の100 MiBを維持し、追加素材も計上する。読込時は作業情報用に256 KiBを予約して保守的に上限を確認する。

画像はブラウザ内で扱い、追加素材をサーバー・第三者・GitHubへ送らない。作業ファイルは元画像、追加素材の画像とファイル名、指定、メモ等を含むため端末で保管する。

## 構造と検証

`src/expression-assets.js`が役割・画像読込・配置初期値・厳密な保存情報検証を担当。`src/expression-asset-panel.js`が操作と選択素材のプレビューを担当。作業ファイルの版5読書きは`src/project-file.js`。

プレビューは元画像と選択中の一枚だけを最大640×960以内に縮小して保持する。変更時に古いビットマップを解放し、遅いデコードや画像確認は世代番号で破棄する。最初の入力画像デコードには最大約64MBの画素メモリ等の負荷が残る。実機スマートフォンでの性能測定は未実施。

自作画像とブラウザテストで、実際の配置画素、透明背景、元PNGバイト、二役割の版5保存と復元、既存結果保持、準備一覧、役割の取り外し、不正画像・配置・役割・寸法・パス拒否、旧版4読込、リセット・新画像による遅い処理の破棄、保存上限を検証する。旧版1〜3の互換や既存の分離・補正・出力は既存テストと合わせて確認する。素材は自作図形であり、実モデルの画質やCubism/VTube Studio読込の検証ではない。

次は、表情素材のグループと表示・重なりを設定し、開閉する形の編集に接続する。素材の品質確認を含む設計を続ける。moc3の作成経路は引き続き未確定。
