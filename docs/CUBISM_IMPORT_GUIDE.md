# WindowsでCubismへPSDを取り込む

2026-10-09に公式資料を確認。オーナーのWindowsにはCubismが未導入。今回は導入・取り込みの手順と検証キットを用意し、Windows/Cubismで実操作したとは扱わない。

## 1. Cubismを用意する

Windows PCで[公式ダウンロードページ](https://www.live2d.com/download/cubism/)を開き、Windows用の通常の安定版と、ページから案内される動作環境を確認する。alpha版は最初の互換確認には使わない。ダウンロードページの「初めてダウンロードする」から進み、利用条件を自分で確認してインストールする。CodexのクラウドにインストールしてもWindows PCに入ったことにはならない。

起動後はFREEとして利用できる選択肢で確認を始める。版によって起動画面が異なるので公式の画面案内に従う。PRO購入や42日間のPRO体験開始はこの手順に必要ない。使用した版とFREE/PRO/TRIALの表示を結果票に記録する。

公式の[機能比較](https://www.live2d.com/cubism/comparison/)では、FREEのアートメッシュ上限は100、テクスチャは2048px一枚。今回の3レイヤーの小さなキットはこの数の範囲内で、テクスチャアトラスや動作付けは行わない。商用利用の判断は後続工程とし、ここでは手元での取り込み確認を行う。

## 2. まず検証キットを作る

[Node.js 24 LTS](https://nodejs.org/ja/download)と[Git for Windows](https://git-scm.com/download/win)があるWindows PCで、新しい保存場所のPowerShellから実行する。既存の作業フォルダーは上書きしない。

```powershell
git clone --branch docs/cubism-import-check https://github.com/tmtchannel69-glitch/ai-live2d-maker.git
cd ai-live2d-maker
npm.cmd ci
node scripts/create-cubism-check.mjs
```

既存チェックアウトを使う場合は未保存の変更を確認・保管してからこのブランチを選び、npm.cmd ciと生成スクリプトを実行する。標準の出力先はtest-results/cubism-check。すでにある場合は記録を保護して上書きしない。再実行は別名の出力先にする。

```powershell
node scripts/create-cubism-check.mjs --out .\test-results\cubism-check-02
```

このキットは自作の図形で、ユーザー画像・AIサーバー・Python・ブラウザ起動は不要。既存のnpm依存だけを使い、実行時の外部通信はない。

| 内容 | 用途 |
|---|---|
| cubism-check.psd | 128×192、体・衣装／顔／髪の3レイヤー |
| layers/*.png | 同じキャンバス位置での各レイヤーの参照 |
| composite.png | 合成した表示の参照 |
| expected.json | 色・透明度・位置・名前の期待値 |
| RESULT.md | 記入する確認票（初期値は未確認） |
| SHA256.json | 配布時のファイル照合用ハッシュ |
| cubism-check.zip | 別端末へ移す場合のキット一式 |

NodeスクリプトのPSD読み戻し成功はCubismの実取り込み成功を示さない。同じPSDライブラリの固定条件で作るキットなので、アプリから出したPSDも次の段階で別途確認する。

## 3. 検証PSDを新規モデルとして開く

1. Cubism Editorを起動し、モデリングの画面を開く。既存モデルの確認とは別に新規モデルを作る。
2. cubism-check.psdをビューへドラッグする。または［ファイル］→［ファイルを開く］からPSDを選ぶ。
3. ［モデル設定］が出たら、PSDから新規モデルを作成する項目を選ぶ。既存モデルへの追加・差し替えは選ばない。公式資料では5.2以前のターゲット向けに別のブレンドモードの項目があるため、指定されたターゲットがない今回は利用するEditorの通常の新規作成を選び、選択内容を記録する。
4. レイヤーがアートメッシュになって並ぶことを確認する。動作付け・自動メッシュ細分化・テクスチャアトラス設定はまだ行わない。
5. 3項目を一つずつ表示し、layers/のPNGと形・位置・透明度を比べる。最後にすべて表示へ戻す。髪は紫、顔は橙、体・衣装は青緑。髪の下端に半透明の帯があり、最下端のalpha=1の行は非常に薄い。composite.pngと色・重なりを比較する。
6. 結果をRESULT.mdへ記入する。保存できる場合はcubism-check.cmo3のような新しい名前で保存し、開き直して表示が保たれるか確認する。元PSDは変更しない。

画面の位置表示やアートメッシュの範囲は、生成時の余白等によってPSDのレイヤー座標そのものと一致しないことがある。モデルの見た目の配置と元キャンバスを基準に比較し、画面の数値だけで失敗と断定しない。

## 4. アプリ出力を確認する

キットを読み込めたら、アプリの保存済み作業ファイルを開いてAI結果を準備する。分離済みの作業ファイルならAIサーバーなしで閲覧・PSD保存できる。Windowsで新たにAI分離する導入はまだ未検証なので、最初のCubism確認と同時に始める必要はない。

必要項目を選び、「レイヤー付きPSDを保存（試作）」と「確認記録付き 制作素材ZIP」、再開用の「作業ファイルを保存」をそれぞれ保存する。最初は少ない項目で確認する。元キャンバス、結果がある項目数、PNGの輪郭、反映したブラシ補正、左右名を記録し、新規モデルとして取り込む。目・髪などの不足があっても、読み込み成否と素材品質を分けて記録する。

重なり順はアプリの仮の順序で、自動推定ではない。画像編集ソフトやCubismで変更した場合は変更前後を記録し、比較用の元PSDは残す。Cubismでの読み込み・色・輪郭確認だけで、瞬きや揺れを作れる素材が完成したとは判定しない。

## 5. 色と画像編集ソフトでの再保存

公式が正常なPSD読み込みを確認している画像編集ソフトはPhotoshopとCLIP STUDIO PAINT。ag-psdなどで生成したPSDは公式保証の対象として案内されていないため、アプリ出力は試作扱いのまま検証する。

すでに使える画像編集ソフトがあれば、元PSDのコピーで次を確認し、別名PSDに保存する。新しい購入・契約は今回の手順に含めない。ソフトがなければキットの直接取り込みを先に行い、「編集ソフトによる確認」「色プロファイル」は未確認と記録する。

- RGB・8bit/チャンネル、一部品一レイヤー、名前の重複なし。
- レイヤーの不透明度と塗りは100%。半透明の輪郭は画素の透明度として残す。
- 不要画素・消し残しを確認し、レイヤーマスクやフィルター等を付けた場合は適用したコピーを作る。一枚の絵に全結合しない。
- 元キャンバスサイズとパーツ位置を維持する。輪郭外の消し残しを除去しても、キャンバスのトリミングで位置を変えない。

アプリとキットのPSDはICCを埋め込んでいない。未タグの画像にsRGBを指定する操作と、既存の別プロファイルをsRGBへ変換する操作を混同しない。元の色空間が不明なら決めつけず未確認と記録する。別プロファイルが設定済みの場合、公式はPhotoshopの［編集］→［プロファイル変換］を案内し、［プロファイルの指定］ではないと明記している。CLIP STUDIOは［表示］→［カラープロファイル］の案内を公式ページで確認する。元PSDとの色差を比較してから保存する。

## うまくいかない場合

| 症状 | 最初に確認すること |
|---|---|
| Cubismが起動しない | Windows・Editor版・公式動作環境・エラー文 |
| PSDが開けない | キットも失敗するか、アプリPSDだけか、RGB8bitとPSD形式、編集ソフトで再保存したコピーとの差 |
| 一項目しかない／足りない | アプリの選択・結果なし件数、デモでないか、全結合していないか |
| 色が違う | 色プロファイル、レイヤー表示、通常合成、不透明度、比較している参照PNG |
| 順序や位置が違う | 仮の描画順、左右の基準、キャンバスのトリミング・移動の有無 |
| 四角い背景や点が残る | 透明度・消し残し、編集で背景を追加していないか |
| 見えない | 全レイヤー表示、表示倍率、極薄の画素、インポート時のエラー |

エラー文と「キット／アプリのPSD／再保存したPSD」のどれで起きたかを報告する。画像の外部アップロードは不要。現在のモデルと元PSDを残し、置き換え前に別名保存する。

## 根拠と現在の確認状況

2026-10-09に以下の公式本文を取得して確認した。動的なダウンロードページの最新インストーラー番号・Windowsでの導入は検証していない。

- [公式ダウンロード](https://www.live2d.com/download/cubism/)・[PRO/FREE比較](https://www.live2d.com/cubism/comparison/)
- [PSDインポート](https://docs.live2d.com/cubism-editor-manual/psd-import/)：ドラッグ／ファイルを開く、新規モデル、5.2以前のブレンドモード、初期メッシュと余白。
- [インポートPSDの作り方](https://docs.live2d.com/cubism-editor-manual/reimport-psd/)：一部品一レイヤー、マスク適用、名前、RGB/sRGB、消し残し。
- [PSD作成上の注意](https://docs.live2d.com/cubism-editor-manual/precautions-for-psd-data/)：公式確認ソフト、RGB8bit、プロファイル変換、PNGとモデル用PSDの違い。

クラウドでは生成スクリプトとPSD/PNG読み戻しを検証する。Windows/Cubism・画像編集ソフトの操作結果は、オーナーが記録するまでは未確認。結果票を記入後、色・位置・透明度などの実際の問題を優先して修正する。

## キットのクラウド検証結果

生成スクリプトを標準の出力先と/tmpで実行。PSDと参照PNGの名前・位置・全RGBA一致、別実装psd-toolsでのレイヤー一致、SHA256とZIPの一致、既存結果票の上書き拒否を確認した。本番ビルドも成功。

保存PSDの合成プレビューは半透明の白マット解除の丸めで、参照合成PNGとRGBに小差が残る。レイヤーの生RGBAは一致し、合成alphaも一致。表示への寄与の最大差は約1.004/255だった。合成プレビューの生RGBまで完全一致とは扱わず、実ソフトで表示を比較する。
