# 画像1枚 → 背景からの前景マスク試作

2026-10-25。すでに実装済みの「画像1枚の入力検査」に、**輪郭だけを自動で切り出す端末内処理**を追加する。目や髪などの33レイヤー分離ではない。

## iPhone操作

1. 「パーツからキャラ生成」→「画像1枚からの自動生成：入力画像の検査」へ移動。
2. PNG / JPEG / WebP（8MiB以下）を1枚選び、画像を768×1024に正規化。
3. 「前景の自動切り抜きを試す」を押す。透明背景画像なら透明度を利用し、ほぼ不透明な画像なら単色で同じ色の四隅とつながる背景を認識する。
4. 前景切り抜きプレビューで背景が消えていることを確認する。
5. ZIP保存で `foreground_mask.png`、`foreground_cutout.png`、`normalized_reference.png`、`source_audit.json` を出力する。切り抜き不成立時は従来の3ファイルのみ保存する。

## 拒否条件・留意点

- 768×1024のCanvas画素以外、誤った入力範囲や閾値は拒否。
- 前景が空に近い、背景が検出できない、4隅が不一致の複雑背景、前景が領域のほぼ全てを占める場合は安全のため切り抜き結果を生成しない。
- JPEG等の白地背景は、背景色の近い**外周に連結するピクセルだけ**を背景扱いする。キャラの内部の同色部分は明示的に背景として消さない。
- 透明PNGでは既存のアルファを利用し、透明領域を保つ。
- どちらも輪郭が不自然・髪の毛が欠ける場合がある。特に単色背景に近い髪色・肌色は外周につながると消える可能性あり。画素精度や美術品質の合格を保証しない。
- 前景マスクの独立した人体パーツ生成数は**0枚**。髪・目・口・服の区別、隠れた顔や髪の補完、Inochi2Dリギングは行わない。
- ChatGPT/APIへ画像を送信しない。課金キー、外部モデル、main統合、デプロイは行わない。

## 確認方法

```sh
node --test scripts/ai-image-pilot/foreground-mask.test.mjs
npm run build
npx playwright test tests/single-image-source.spec.js --workers=1
```

テストでは透明画像・単色背景・内部の背景に似た色・四隅不一致・無地・境界接触・偽の寸法を確認。E2Eは前景PNGのアルファと保存レポート、無地背景の拒否を確認。GitHub Actions完了時点で合否を判断する。画像の主体認識・実キャラ品質は別の未完工程。
