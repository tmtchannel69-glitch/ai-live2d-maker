# 開閉に合わせた表示範囲

2026-10-11。包括承認と継続依頼内で、独自Canvas合成の範囲に開閉2位置を追加。範囲の外に出た選択素材を隠し、目・口のはみ出しを調整する機能。

## 操作

1. 素材を選び、固定範囲を反映する。長方形・楕円と位置/幅/高さを指定する。
2. 「編集する範囲」で閉じた（0）または開いた（1）を選び、「範囲の動きに使う値」で左目・右目・口を選ぶ。
3. 数値または「指で表示範囲を調整」で編集する。形は2位置で共通なのでキー編集時には選べない。専用画面には対象素材・開閉位置・使う値を表示し、対象位置の実際の合成を下書き表示する。確定まで本設定は変わらず、閉じると下書きを破棄。
4. 反映/確定すると初回はもう一方を固定範囲から作る。開閉スライダーで途中の範囲も確認し、自動再生と併用できる。

「閉じた範囲を薄くする」は現在の入力範囲の位置・幅・形を保ち、中心から高さを5%に縮めて反映する。最小高さは元画像の0.01%で、完全な非表示を保証しない。完全に隠すには既存の表示条件も調整する。

「範囲の開閉を解除」は2位置を外し、保持されている固定範囲を使う。固定範囲の編集は2位置を自動変更しない。固定範囲自体を解除すると関連キーとグループの範囲追従も外す。再生中は編集禁止。素材/元画像/配置の変更、読込・保存・リセット・他処理は下書きを閉じる。履歴は保存しない。

## 描画と制限

閉じた→開いたの x・y・幅・高さを0〜1の値で直線補間する。形は同一の長方形/楕円。固定範囲を置き換える独立の設定で、9点メッシュの輪郭を自動で写す処理ではない。9点変形・表示条件・重なり順と併用でき、表示条件で非表示なら範囲編集でも表示しない。

範囲は元画像座標。グループ追従ありは補間した範囲に素材と同じ親子変換を掛け、なしは元画像上へ固定する。向きの動き・開閉変形・範囲補間はそれぞれ独立に評価して合成する。他素材や背景へクリップを掛けず、元PNG・素材配置・素材ZIP・PSDを変更しない。

移動/サイズの値の制限は従来範囲と同じ。元画像の外へ右/下がはみ出た分は描画されない。自由な輪郭、別素材をマスクにする機能、範囲の自動生成、立体的な顔の向き、moc3/VTube Studio出力は未対応。

## 作業ZIP版11

`expressionClipKeys` に役割ごとの `{driver:'left'|'right'|'mouth',closed:{shape,x,y,width,height},open:{shape,x,y,width,height}}` を保存する。固定の `expressionClips` を必須として保持。グループ・向きの設定を含む既存情報も保持する。

未知/画像なし/固定範囲なしの役割、未知の使う値、不足/余分な項目、2位置で異なる形、文字列・非有限/範囲外の値、ゼロ幅・高さを拒否し、現在の作業を保持する。旧版1〜10は範囲キーなしとして読める。版10に新項目を混ぜたファイルは拒否。以前のアプリでは版11を開けない。解除後は残った設定に応じた従来版で保存する。

素材置換ではキーを維持、素材削除・固定範囲解除で関連キーを外す。新画像・リセットで全キーを整理する。スライダーの値・再生・下書き・履歴は保存しない。読込は左右の目1、口0、向き0から再開。

自作サンプルに口内部の開閉範囲を設定し、版11で保存・再開できる。AI・外部画像・画像送信・新しい依存を使わない。実機・実キャラクターの自然な表情品質・Live2D互換は別途検証が必要。
