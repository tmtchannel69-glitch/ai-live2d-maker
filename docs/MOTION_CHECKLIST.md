# 動きの設定チェックと即時プレビュー

2026-10-11。オーナーの「ある程度進めて」と包括承認内で、スマホから次の編集先を選べる一覧を実装。

## 一覧

動きの入口に顔全体・左目（画面右）・右目（画面左）・口のカードを表示する。詳細は確認候補のある部位を初期展開し、それ以外を折りたたむ。同じ作業中は開閉状態を維持する。役割数と確認候補数を表示する。

- 素材：読込済み役割を表示し、部位の素材がなければ推奨役割の読込へ案内する。すべての役割を必須とはしない。
- 表示：無効な素材があれば案内する。閉じる/半分/開くで、その部位のどの素材も表示対象にならない場合に確認候補とする。画像の内容を解析するものではない。
- 開閉の形：変形設定の件数を表示。部位と違う値で動かす素材を候補にする。変形なしも候補として案内するが、画像切替のみも利用可能。
- 表示範囲：固定/開閉の件数と、部位と違う値で動かす範囲を表示。範囲なしは任意の案内で、必須の不足とはしない。
- まとめ方：未所属・別部位のグループ所属を確認候補にする。顔全体への直接所属は許容する。意図した設定をユーザーが確認し、勝手に割り当てない。
- 向き：部位の左/中央/右の設定あり・なしを表示する。親や通常の配置も使えるため、未設定を必須の不足とはしない。

件数は設定から作った候補で、完成率ではない。候補ゼロを品質確認済み・自然な表情・立体的な向き・Live2Dモデル完成と判定しない。顔カードは下地の肌を扱い、子部位の素材は各カードで確認する。

## 編集先と試す操作

行のボタンは対象役割を選んで読込・表示・変形・範囲へ移動する。まとめ方は通常のグループ編集の入口へ、3位置は対象グループのキー設定へ移動する。移動では設定を変更しない。合成準備中は待って再操作する案内を表示する。

部位の閉じた状態/半分/開いた状態は、対応するスライダーだけを0/.5/1へ合わせ、合成画面へ焦点を移す。顔は向き−1/0/1。合成画面にも対象を選ぶ欄と3状態のボタンを設ける。再生中は停止し、他のスライダー値・素材・設定を維持。未確定の専用編集を閉じ、下書きを破棄してから試す。処理ロック中は操作を禁止し、素材なしでは試すボタンを無効にする。

## 保存と更新

「動きの確認一覧を保存」は設定情報と候補、制限を画像なしのテキストとして端末に保存する。外部送信せず、作業再開用ファイルやLive2D出力ではない。読込名・画像データを含めない。

一覧は現在の素材/表示/変形/範囲/所属/キーから作り、変更・解除・素材削除・作業読込で更新する。新しい保存項目や版を追加せず、作業ZIP版1〜11の設定で再現する。一覧の開閉・スライダー値・再生状態は保存しない。元画像・PNG・制作素材・PSDは変更しない。
