# 表情素材をまとめて動かす設計

2026-10-11。直前の提案「複数の素材をまとめて動かす仕組みを設計」に対するオーナーの「続けて」で設計を実施。本文は次の実装案で、グループ操作・保存・追従は現在のアプリに未実装。

## 使う場面と最初の範囲

白目・瞳・まぶたを毎回別々に移動せず、左目の素材としてまとめて動かす。顔全体を傾けた際には、左右の目・口も一緒に動く。既存の素材ごとの配置、9点の変形、重なり順・表示条件をそのまま組み合わせる。

最初は追加した表情素材15役割だけを対象とする。既存のAI結果を動かす頭・髪の試作とは独立する。元画像の背景も固定の位置確認用。自由なグループ作成・親の付け替え、開閉へのグループ動作の結び付け、顔追跡は後続工程とする。

| グループ | 親 | 初期割り当ての候補 |
|---|---|---|
| 顔全体 `face` | なし | 目・口の下地の肌 |
| 左目 `left_eye`（画面右） | 顔全体 | 左の白目・瞳・まつげ/まぶた・閉じた目 |
| 右目 `right_eye`（画面左） | 顔全体 | 右の白目・瞳・まつげ/まぶた・閉じた目 |
| 口 `mouth` | 顔全体 | 上唇・下唇・口内部・歯・舌・閉じた口 |

一つの素材は一つのグループか「まとめて動かさない」に所属する。顔全体は子グループの素材にも作用するため、二重に割り当てない。親子の構成は固定し、循環を作れない。自動割り当ては読込時に行わず、「役割に合わせてまとめる」を押したときに候補を下書きへ設定する。

## スマホでの操作

合成画面の近くに「素材をまとめて動かす」入口を置き、専用画面で合成と操作を同時に見る。

1. 顔全体・左目・右目・口を大きな選択欄で選ぶ。含まれる素材と親を表示する。素材の割り当ては一覧の選択欄で変更できる。
2. 指の操作を「移動」「回転」「大きさ」「中心点」「拡大画面を移動」から選ぶ。一指操作を基本にし、ピンチを必須にしない。
3. 移動は表示中のグループ枠内、回転・大きさは専用の持ち手、中心点は中心の印をドラッグする。小さな枠も選択欄で対象を選べる。親グループの枠は子孫の素材を含む。
4. 矢印と数値入力で微調整。拡大1〜4倍、操作履歴最大30件、取り消し・やり直しを用意する。
5. 「まとめ方を確定」で割り当て・変換・範囲追従を一括反映する。閉じる・変更せず戻る・Escapeは開始前を保持する。再生中は停止して開く。

中心点の初期値は元画像の中央。グループを選び「素材の中心に合わせる」を押すと、そのグループと子孫の素材の元の配置の外接矩形の中心へ合わせる。位置は元画像上の値で、変形後や回転後の輪郭から自動計算しない。素材追加・置換で勝手に中心を更新しない。回転・拡縮後に中心を変えると見え方も変わることを操作欄に説明し、下書きで確認する。

「このグループを元に戻す」は選択グループの変換だけを初期値へ戻す。所属・子グループの調整は保持。「まとめて動かす設定を解除」は全割り当て・変換・追従を解除し、素材の元の配置・変形・表示範囲を保持する。両操作は専用画面内の取り消しが可能。

処理・保存中は編集禁止。元画像変更、素材追加・置換・削除、作業読込、リセット、他の処理開始で下書きを閉じる。回転・画面非表示・キャンセルされたポインター・二本目の指は進行中の操作を開始前へ戻す。描画元の画像を借り、閉じると参照を解放する。主要操作は48px以上、入力文字16px以上、320px幅・横画面で横にはみ出さない。

## 表示範囲との関係

既存の長方形・楕円の範囲は元画像上に固定される。その動作を既定として維持する。素材ごとに「表示範囲もグループと一緒に動かす」を明示的に選べる。範囲と所属がある素材だけ有効にする。

追従ありなら素材と範囲へ同じグループの移動・回転・拡縮を適用する。目を横へ動かしても範囲だけ元の場所に残ることを防ぐ。範囲の値を保存のたびに書き換えず、描画時に変換する。9点メッシュの瞬き・口の開閉に範囲の形が追従する機能は今回の案に含めない。

追従を解除すると範囲は元画像上へ戻り、素材の一部が見えなくなる場合がある。下書きでその結果を表示する。既存の範囲編集では元画像上の値を編集し、追従時には「グループを適用する前の範囲」と説明する。合成で見えている座標をそのまま保存する誤差を避ける。

## 座標と描画の実装案

元の配置・変形点を変更せず、描画の外側にグループの変換を重ねる。元画像の幅をW、高さをHとし、実ピクセル座標上で変換する。割合の座標を直接回転して、縦長画像の角度や比率を歪めない。

各グループの保存値は `dx,dy,pivotX,pivotY,angle,scale`。移動と中心は元画像に対する割合、角度は度、倍率は縦横共通。初期値は移動0、中心0.5、角度0、倍率1。検証範囲は移動−1〜1、中心0〜1、角度−180〜180、倍率0.1〜4。負の倍率・ゼロを認めない。

局所変換は次の順序で定義する。右端から点へ作用する。

`L = T(dx*W, dy*H) × T(pivotX*W, pivotY*H) × R(angle) × S(scale) × T(-pivotX*W, -pivotY*H)`

顔全体は `Mface=Lface`、子は `Mchild=Mface×Lchild`。親の移動・回転・倍率は子の中心にも作用する。親が傾いているときの子のドラッグは、画面上の差分へ親行列の逆の線形部分を適用してからW/Hで割り、局所移動に戻す。CSS表示倍率・拡大・スクロールも除いてから計算する。素材そのものの配置は書き換えない。

描画順は全素材の既存の重なり順を維持し、グループごとに並べ替えない。素材ごとに以下を実行する。

- 表示条件で非表示なら描かない。
- コンテキストを保存する。固定範囲はグループ変換前にクリップする。
- 所属の合成行列を適用する。追従範囲は変換後にクリップする。
- 素材の元の配置と9点の補間形で描く。
- コンテキストを復元し、次の素材へ範囲や変換を持ち越さない。

変形のガイドも同じ行列で表示し、ガイドが範囲外に表示される既存仕様を維持する。グループ操作の持ち手・中心点は画面上の大きさを一定に保つ。個別の配置・9点編集はグループ適用前の値を扱うと画面内に説明する。

## 保存形式の案

グループ設定がある場合だけ作業ファイル版9を使う。現在のアプリは版8までで、版9は未実装。旧版1〜8はグループなし・追従なしで復元し、見え方を維持する。

`expressionGroups`を次の三辞書として追加する。

| 項目 | 内容 |
|---|---|
| `transforms` | 四つの既知グループIDに対応する変換値。未記載は初期値 |
| `assignments` | 読込済みの役割から既知グループIDへの所属。未記載は所属なし |
| `clipFollow` | 所属と表示範囲のある役割の `true` のみ。未記載は固定 |

親は固定なので保存しない。グループ解除後は残った設定に応じて版8以下へ戻す。版9では従来の表示・変形・範囲の辞書も含め、空なら空辞書を保存する。古いアプリは版9を開けないことを案内する。元PNG・制作素材ZIP・PSDは変更しない。

未知のグループ/役割、対応画像不足、余分なキー、文字列・非有限数・範囲外の値、追従に必要な所属や範囲の不足を拒否する。不正ファイルでも現在の作業を保持する。素材削除でその役割の所属・追従だけを外し、グループの変換と他素材を保持する。素材置換は設定維持。所属解除・範囲解除ではその役割の追従も外す。新画像・リセットでグループ設定を整理する。下書き・履歴・表示倍率は保存しない。

## 実装順序と確認条件

最初の実装は、固定の親子構成・所属・移動/回転/縦横比を保った拡縮、専用画面の下書き操作、範囲の任意追従、版9での保存・復元を一つの試作としてまとめる。開閉キーへの結び付けは、これが確認できた後に進める。

| 確認 | 成功条件 |
|---|---|
| 親子と独立操作 | 顔で子が一緒に動き、左目だけでは右目・口が動かない。所属なしは動かない |
| 縦長画像の行列 | 中心まわりの90度回転と親子の移動・拡縮が実画素上で設計どおり |
| 既存変形との併用 | 瞬き・口の途中の形を保ったままグループ操作が作用する |
| 範囲 | 固定/追従で異なる正しい画素になり、他素材・背景へ漏れない |
| 重なり | 所属を変えても表示条件と全素材の順序を保持する |
| タッチと下書き | 親の回転後も指の方向へ動く。取消・戻るで元の設定を保持し、確定だけ保存対象になる |
| 再開と互換 | 版9の画素・設定を再現、版1〜8は従来どおり。不正設定は現在の作業を置き換えない |
| 整理と出力 | 素材/範囲/所属の解除、リセット、画像変更を扱い、元PNGのバイト列と素材出力を保持する |
| 画面 | 320px幅・横画面の横はみ出しなし、48px以上の操作領域。実機確認は別に記録 |

現在のコードの接続先は `expression-scene.js` の素材別描画、`main.js` の状態・素材変更・保存スナップショット、`project-file.js` の版と検証。グループ状態・行列は独立モジュール、指の操作は専用画面へ分ける。既存の配置編集に回転を無理に混在させない。

これは独自プレビューの制作機能で、Live2Dのデフォーマーやmoc3出力そのものではない。外部サービス・画像送信・SDK導入・契約・費用・公開を追加しない。VTube Studio対応の出力経路と実モデルの確認は引き続き別の未完了項目。
