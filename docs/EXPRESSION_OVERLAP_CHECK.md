# 重なりと元画像の下地を確認する

「表情を拡大して確認」で対象素材を選び、「重なりの確認」を切り替えます。

| 表示 | 確認すること |
|---|---|
| 通常の合成 | 他の素材との重なり・開閉・向き |
| 選んだ素材を一時的に隠す | 対象素材を消しても同じ場所に絵が残るか。ほかの素材や、薄く重ねた元画像が表示される |
| 元画像だけを表示 | 元の目・口が元画像に描かれたままか。元画像は動かない |

単独表示と元画像の薄い比較のチェックは通常表示で操作します。一時的に隠す場合は薄い元画像比較の選択を保持し、単独表示を一時無視します。通常に戻すと両方の選択を復帰します。隠した素材への拡大移動はその素材が本来描かれる位置を使います。

3状態比較も使用できます。切り替えで比較範囲が変わらないよう、選択素材の本来の3状態の描画範囲を使います。カードの素材の表示有無は本来の表示条件を表し、一時非表示の状態そのものは選択欄と説明で確認します。

確認メモの記録・記録した状態の再表示は通常表示へ戻して行います。追加した表示方法を作業形式へ保存しないため、誤った再現状態を記録しないよう制限しています。入力中のメモは表示切り替えだけでは破棄しません。

画像や表示設定を変更する機能ではありません。自動の重複判定、背景の目・口を消す処理、隠れた肌の生成は行いません。問題が見つかったら既存の表示/形/範囲編集へ戻るか、用意した下地PNGなどを素材として読み込んでください。完成モデルの出力とは別の確認操作です。
