## 出力とデータ

完成画像768×1024、独立PNG33枚、manifest/rig/intermediate/recipeの4JSON、説明をZIPの39項目へ格納。展開パーツRGBAは7,036,208bytes。最終ZIPは2,137,727bytes、SHA256 `7c711bcc03f24b7733d2bd516324a90440812a0c516e705c6c08d577ec1a1d0c`。

face_baseは目や服を焼き込まず、目の下にも肌を描く。虹彩/反射は単独PNGでは完全な形を保持し、合成時に白目のalphaでクリップ。口内は非空PNGを保存するが、通常顔では非表示。親子/支点/前後順は固定テンプレートに従って自動設定し、襟/リボンは胴体へ所属する。

中間データは8グループ+33Part、297頂点/264三角形。親からworld座標を再計算すると元PNGの配置と一致する。新しいパーツは意図的に重なるため、従来の「元画素を重複所有しない」共通部品形式とは分けた。既存のworker/API/最小/詳細/頭/髪の生成器を変更していない。
