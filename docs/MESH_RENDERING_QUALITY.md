# 変形プレビューの継ぎ目改善

9点のメッシュで素材を変形すると、三角形の境界に細い線や隙間が見えていました。境界のぼかしによる被覆率を通常の重ね方で合成すると、隣接する二つの三角形の透明度が不足するためです。修正前の画素テストでは、不透明素材の内部が255から191まで低下しました。

素材一枚を一時キャンバスへ描き、隣接する三角形の被覆率と色を加算してから、完成した素材を通常の方法で重ねます。三角形を広げる処理は加えず、外周の透明度・透明な穴・半透明の絵を維持します。他の素材はこの加算に含めません。親子の移動/回転/拡縮、表示範囲、描画側の透明度は最後の合成で適用します。

## 端末への配慮

描画先ごとに一時キャンバスを再利用し、毎フレーム/素材ごとのキャンバス作成を避けます。変形後の領域だけを確保し、親子の変換前に画面外にある素材も切り捨てません。各描画の直後に一時画素を消し、ユーザー画像をキャッシュとして残しません。OffscreenCanvasを使えない環境では通常のCanvasに切り替えます。外部通信や新しい依存パッケージは追加していません。

クラウドChromiumの390×844画面で、自作サンプルの口スライダーを60回変更。画面の同期更新時間は中央値3.0ms、95百分位7.9msでした。既存テストと並行した参考値で、スマホ実機の速度や画面表示までの時間の保証ではありません。

## 検証と制限

通常ブラウザテスト95件（新規3件＋既存92件）と本番ビルドが成功しました。実SAM推論/サーバーテストは今回は再実行していません。

- 不透明/半透明の素材、直線/中心点をずらした変形で内部の透明度と色を確認。
- 半透明の素材を17段階で変形し、親の回転・描画透明度・表示範囲と組み合わせて確認。
- 同じ描画先を使い回したときの古い画素、負の座標から親の移動で画面内へ戻る素材を確認。
- 模様の恒等変形と透明な穴の画素を確認。
- スマホ幅の詳細確認で口を400%に拡大し、以前の三角形状の継ぎ目が消えたことを目視確認。画像は自作図形のみで、スクリーンショットはGitHubへ保存しない。

元PNG・PSD・作業ファイル版1〜11の形式と設定は変更しません。合成、詳細確認、グループ/範囲の下書き、指でのメッシュ編集が同じ描画を使います。縮小プレビューのぼけ、素材不足や隠れた部分、自然な瞬き/口の形を解決する変更ではありません。Safari/iPhone/Android実機の描画とメモリ、Live2Dモデル生成とVTube Studioでの確認は未完了です。
