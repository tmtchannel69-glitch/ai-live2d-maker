# 分離結果から動きの素材を作る

スマホで「分離 → 補正 → 表情素材へコピー → 位置/動きの調整 → 保存」の流れを、PNGを保存して読み直さずに進められます。外部サービスへの新たな画像送信や画像生成は行いません。

## 使い方

1. 画像を選び、AI試作で使うパーツの点/枠を指定して分離します。必要に応じてブラシで補正します。AI試作サーバーの準備はREADMEを参照してください。
2. 「動き」から「素材の読み込みへ」を選び、「素材の役割」を決めます。「分離済みのAIパーツを使う」を開いて結果を選び、コピーします。別のパーツ構成にあるAI結果も選べます。
3. 元画像と同じキャンバスのまま、配置は左上0%、幅/高さ100%にします。透明な余白も位置合わせに必要です。元の分離結果や補正は変更しません。指定変更前なら注意表示を確認します。
4. 素材の細分化、閉じた目・口や下地の肌など、役割に合う絵があるか確認します。「目まるごと」をコピーしただけで白目/瞳/まぶたが自動で分かれることはありません。元画像にない絵も生成しません。
5. 合成・編集画面で重なり順、表示条件、開閉の形や範囲、グループと向きの設定を調整します。動きの設定チェックから対象の編集先へ移動できます。
6. 「保存」工程で作業ファイルを端末へ保存してください。再開用のZIPには分離結果と追加素材の両方が入ります。

一つの役割に一枚まで。既存素材があれば、ボタンを「置き換える」と表示します。コピー時は配置を元の位置へ戻し、既存の表示/変形/範囲/グループ設定は保持します。取り込み後は独立したコピーなので、分離結果を再生成・補正しても自動更新しません。更新する場合は同じ役割へコピーし直し、動きを再確認してください。

デモは切り出した位置情報を保持しないため、このコピーの対象外です。AI結果も元画像と異なるサイズや10 MiB超過は拒否し、以前の素材を保持します。元PNGの透明度とバイトを保持します。処理中は他の設定/出力を制限し、失敗時は再実行できます。リセットや画像変更後に遅いコピーが戻ることはありません。保存形式版1〜11を維持します。

## 配置済み表情PSD

「保存」の「配置済み表情素材のPSDを保存（試作）」は、追加した全表情素材を元画像と同じキャンバス上に並べたレイヤー付きPSDです。分離結果そのもの・元画像は含みません。追加素材だけで使えます。

- レイヤー名は日本語の役割名と役割ID。重なりは表示順order、同じ値はアプリの役割順。
- 配置のx/y/幅/高さを反映し、キャンバス外は切り落とします。縮小/拡大・位置合わせは画像に反映するため、PSDでの画素は元PNGと一致しない場合があります。元PNGと設定は作業保存・引き継ぎZIPで別途保持します。
- 左右の目・口がすべて開いた状態（各1）を初期表示にします。閉じた素材や表示無効の素材も非表示レイヤーとして含み、削除しません。合成画面の一時的な値/再生状態は出力に使いません。
- 開閉メッシュ、クリッピング/表示範囲、グループ変換/3位置、頭と髪の動きはPSDへ反映しません。独自設定は引き継ぎZIPへ保存します。
- PSDはRGB・8ビット、sRGB想定。16ビットやICCプロファイル付きPNGなど対象外は拒否します。元PNGは保持します。ファイル上限100 MiB、入力各10 MiB、画像量の計算上限128 MiB。端末の実際のピークメモリの保証ではありません。
- 作成は別の処理で行い、リセット・画像変更時に中止します。失敗時も作業を保持し、ZIPや元PNGを取り出せます。

画像編集ソフトでレイヤー位置・透明度・はみ出し・非表示の表情素材を確認し、必要に応じて描き足し/修正してください。Cubismでの実読込は未検証です。PSDは完成Live2DモデルやCubismプロジェクトではありません。

## 保存の使い分け

| 保存 | 用途 |
|---|---|
| 作業ファイル | このアプリで続きを編集。元画像を含む |
| 素材と動きの設定ZIP | 全分離PNG・追加PNGと独自設定/確認資料を渡す。元画像なし |
| 配置済み表情PSD | 追加した表情PNGを画像編集・モデル制作へ渡す。動き設定なし |
| 結果画面の制作ZIP/PSD | 選択中の分離結果を渡す。追加素材は含まない |

## VTube Studioで使うまで

アプリ内での試作・素材出力までを今回の実装範囲とします。有効なmoc3/model3.json/テクスチャを作る機能はありません。2026-10-11に公式の[外部連携API一覧](https://docs.live2d.com/en/cubism-editor-manual/external-application-integration-api-list/)と[組み込み用書き出し](https://docs.live2d.com/en/cubism-editor-manual/export-moc3-motion3-files/)を再取得しました。API一覧のMOC3出力通知は書き出し完了を受け取る機能で、素材からモデルを作成するAPIとは区別します。今回確認した公式手順はCubism Editorでモデルを制作してmoc3/model3.json/テクスチャを出力する経路です。Cubismを使わない自動生成を実現したとは扱いません。

現時点の具体的な残工程は、素材の修正、モデル制作側でのメッシュ/変形/パラメーターの設定、moc3等の書き出し、VTube Studioでの実読込と追跡確認です。既定のパラメーターなどは[モデル制作方針](MODEL_AUTHORING.md)、取り込み確認は[Cubismへの取り込みガイド](CUBISM_IMPORT_GUIDE.md)を参照してください。Editorの導入・利用条件、SDK契約や費用、公開/main統合は別途判断します。
