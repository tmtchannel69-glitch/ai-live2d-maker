# スマートフォンを基準にする開発方針

オーナーは将来的なスマホアプリ化を希望。現在のWebアプリもスマホで作業を完了できる操作を基準に改善する。PC操作は併用できるよう維持する。

- 縦画面を基本に、320〜430pxの幅と横画面を確認する。
- ボタンは原則48px以上、入力文字は16px以上。狭い画面でも横にはみ出さず、文字を拡大できるようにする。
- 細かい点は画像の拡大、指のドラッグ、矢印による微調整で扱う。マウスのホバーやキーボードだけを前提にしない。
- 画像と操作を一つの編集画面にまとめる。確定・戻る操作を明示し、途中の誤操作は取り消せるようにする。
- スクロールと画像編集を区別する。画面の移動、キャンセル、複数指、端末の向き変更で意図しない編集を確定させない。
- 画像は端末の作業ファイルで保存・再開する。クラウドへの自動保存や外部送信は別途承認対象。
- ブラウザでのタッチ再現・画面幅のテストと、iPhone/Androidの実機確認を区別する。

## 今回の改善

表情素材の専用編集画面で、9点のドラッグ、1/2/3倍の拡大、拡大画面の移動、点の選択と0.5%単位の矢印調整に対応。最大30操作の取り消し・やり直しを用意。下書きは「形を反映」で確定し、閉じる・戻る操作で破棄する。作業ファイル版7は従来のまま。

全体のスマホ向けボタンと入力欄の大きさ、素材読込の縦配置も改善した。画像分離・補正・素材準備の長い画面構成は今後段階的に整理する。

## 将来のアプリ化

まずスマホでの画像選択→分離→補正→動作編集→保存の流れを整える。実機でファイル操作・メモリ・タッチ・画面回転を確認した後、ホーム画面から使うWebアプリやiOS/Androidアプリの方式を比較する。今回、アプリ化の方式選定、ストア公開、契約・課金は行っていない。
