# 表情の3状態を比較

詳細確認の「3状態を並べて比較」で、閉じた・途中・開いた表情を同時に確認します。完成モデルの判定や自動品質確認は行いません。

## 操作

1. 確認する素材を選び、「3状態を並べて比較」を押します。
2. 比較する動きを左目/右目/口/顔の向きから選びます。目/口は0・0.5・1、向きは-1・0・1を表示します。他のスライダーは現在の値を使います。比較の動きは素材を選び直しても維持するため、必要なら選び直してください。
3. スマホでは画像欄を左右へスクロールします。キーボードでも画像欄にフォーカスして矢印で移動できます。操作欄のスクロールは画像欄と独立しています。
4. 気になる画像の「この状態を詳しく」で1状態の確認へ戻ります。比較した値だけを一時スライダーへ引き継ぎ、素材が見える場合は400%でその位置へ移動します。非表示の場合は表示条件/範囲を調べてください。
5. 表示/形/範囲の編集へ移動できます。移動しただけでは設定は反映しません。編集画面では対象キーを確認してから変更してください。

「1状態の確認に戻る」は比較開始前のスライダー値を保ちます。「この状態を詳しく」は選んだ比較状態へ変えます。比較中の拡大率と移動操作は無効で、3枚を共通倍率で表示します。

## 比較する範囲

選択素材だけを小さな確認キャンバスへ3回描き、実際に表示された3状態の範囲を合わせて余白を付けます。3枚を同じ範囲/倍率へ切り出すため、途中のサイズの違いや位置ずれが残ります。状態ごとの自動拡大で差を隠しません。3状態すべてが非表示なら全体を表示して案内します。小さい確認キャンバスで範囲を検出するため、極端に細い線は見つけられない場合があります。

合成表示では他の素材もその範囲に見えます。「選択素材だけを確認」で重なりを外せます。選択素材が非表示のカードにはその旨を表示します。他の素材や比較用の元画像が見えていても、選択素材が見えているとは限りません。

メッシュの補間・表示条件・固定/開閉範囲・親子/3位置の動きのキーを合成と同じ描画で反映します。「鮮明に確認」の画像も共有し、比較のために元PNGを3組読み込むことはしません。元画像を薄く重ねた際は元の絵が残るため、最終的な表情は比較表示を外して確認してください。

## 保存と負荷

比較の動き、画像、比較範囲、確認用の値は作業ファイルへ保存しません。元PNG・PSD・版1〜11の作業設定は維持します。自動で品質確認済みと記録しません。比較画像は384×256の3枚、範囲の検出は最大320×480。既存の確認用キャンバスを描画に使い回し、閉じる/戻る/リセットなどで比較画素を消します。画像を外部へ送信/保存しません。

3状態を描く分、1状態より処理が増えます。スマホ実機の速度/メモリ、自然な瞬き・口の完成、Cubism/VTube Studio読込は別途検証が必要です。moc3生成は未実装です。
