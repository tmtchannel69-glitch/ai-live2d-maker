# 素材と動きの設定の引き継ぎ

「保存」工程の「素材と動きの設定をZIP保存」で、ai-live2d-handoff.zipを端末へ保存します。追加した表情素材だけでも、画像を選んだ直後の確認資料だけでも出力できます。画像はブラウザ内でまとめ、新たな送信は行いません。

## 入るもの

- parts/：現在保持している全構成の分離PNG。選択解除した結果や別構成も含みます。AIとデモ、ブラシ補正、元サイズ、位置の扱いを区別します。
- expressions/：追加した表情PNG。非表示の素材も含み、元のPNGをそのまま保存します。配置や変形を画像に焼き込みません。
- handoff.json：独自形式の版1。元画像の幅/高さ、PNGの役割/サイズ、配置、実効表示設定、9点メッシュの接続と開閉キー、固定/開閉表示範囲、固定の親子構成、所属/範囲追従、左/中央/右のキー、分離パーツの頭/髪の試作設定、全確認記録。
- PART_CHECKLIST.txt：全結果の処理方式、指定の一致、現在の境界確認、描き足し、メモ。結果のない項目は含みません。未分離で記録だけある項目の記録はJSONのreviewsに残ります。
- MOTION_CHECKLIST.txt：顔/左右の目/口の素材・表示・形・範囲・所属・向きの確認候補。設定の有無を示し、自然さや品質を確認済みとはしません。
- README.txt：座標・補間・親子変換・画像の使い方と制限を日本語で説明。テキストはUTF-8 BOM付きです。

元画像、元の読込ファイル名、指定点/枠/履歴は含みません。画像のパスは役割IDで固定します。確認メモは含むため、他の人へ渡す前に内容を確認してください。

## 設定の読み方

左上原点、右がx、下がy。配置と範囲は元画像の幅/高さに対する比率です。9点の座標は素材配置内の比率、mesh.gridとmesh.trianglesが元の点と接続です。開閉値は0〜1、表示条件のopenは0.5以上。表示順はorderの小さい順、同値ならexpressionRoleOrder順。

グループは顔全体を親として左右の目/口を動かします。未所属は独立。通常変換の未設定値はdx/dy=0、pivotX/pivotY=0.5、angle=0、scale=1。dx/dyと支点は元画像基準、angleは度です。向きの3キーは−1/0/1で全値を線形補間し、キーがあるグループは通常変換を置き換えます。その後に親変換を合成します。表示範囲の開閉2キーは0〜1で線形補間し、clipFollowがtrueなら所属グループの変換に追従します。

AI結果は元画像と同サイズで左上位置を保持。デモ結果は固定領域の切り出しで元画像上の位置情報を保持しないため、配置の再確認が必要です。指定変更後のAI結果は、記録が確認済みでも現在の境界を未確認として記載します。

## 制限と別の保存

これは独自の引き継ぎ資料です。CubismプロジェクトやLive2Dモデルではなく、Cubism/VTube Studioへの直接読込はできません。moc3出力、Cubismの変形/パラメータへの変換、自然な表情・立体的な顔の完成は未実装です。モデル制作側での画像編集・動きの設定・実ソフトでの検証が別途必要です。

このアプリの「作業ファイルを開く」でも復元できません。開発を続ける際は「この作業を端末に保存」で作業ZIPを別途保存してください。作業形式版1〜11は変更していません。既存の制作素材ZIPとPSDの対象/挙動も維持します。

上限は合計100 MiB、分離PNG32 MiB、追加PNG10 MiB、設定256 KiB。大きすぎる画像は読込前に拒否し、設定・PNGサイズも確認します。失敗しても現在の作業を保持し再実行できます。処理中の設定変更を制限し、画像の再選択/リセット後は古い作業のダウンロードを行いません。端末ごとのメモリや実機のファイル保存は別途検証が必要です。
