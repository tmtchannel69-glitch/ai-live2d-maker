# 素材グループの操作と制限

2026-10-11。オーナーが通常開発の継続を承認し、設計済みの固定の親子グループを独自プレビューへ実装。設計記録は[こちら](EXPRESSION_GROUPS_DESIGN.md)。

## 操作

1. 追加PNGを読み込み、合成画面の「素材をまとめて動かす」を開く。
2. 「役割に合わせてまとめる」で顔全体→左右の目・口へ素材を割り当てる。読込時には自動適用しない。「素材のまとめ方と表示範囲」で素材ごとの所属を変え、「まとめて動かさない」も選べる。
3. グループを選んで移動・回転・大きさ・中心点を指で編集する。移動は枠内、回転と大きさは黄色の点、中心点は青い印を動かす。中心を変えると回転や拡縮後の見え方も変わる。
4. 矢印は画面上の方向へ元画像の0.5%ずつ移動し、回転は1度、大小は現在の倍率の5%ずつ調整。1〜4倍の拡大、拡大画面の移動、数値の微調整、最大30操作の取り消し・やり直しが使える。数値入力は「数値を下書きに反映」で適用し、入力しただけでは適用しない。
5. 「まとめ方を確定」で所属・変換・追従を一括反映。閉じる・変更せず戻る・Escapeでは元の設定を保持する。確定前の下書きと履歴は作業ZIPに含めない。

「素材の中心に合わせる」は所属する素材と子孫の元の配置の外接矩形の中心を使う。透明余白や9点変形の輪郭は解析しない。素材の置換で勝手に中心を変えない。「このグループを元に戻す」はその変換だけを解除。「まとめて動かす設定を解除」は全所属・変換・追従を外す。素材の元の配置・9点変形・範囲は保持する。専用画面内では両操作も取り消せる。

## 範囲・個別編集

顔全体の移動・回転・縦横比を保った拡縮は子の目・口にも作用し、子の操作は他の子へ作用しない。対象は追加した表情素材で、頭・髪のAI結果を動かす別の試作や元画像背景は動かさない。

表示範囲は既定では元画像上に固定。所属と範囲がある素材だけ「表示範囲も一緒に動かす」を選べる。素材と範囲へ同じ親子変換を適用し、範囲編集の枠・指の位置も変換する。追従を外すと範囲は元の場所に戻る。9点の開閉形への範囲の変形は未対応。

素材の配置・9点・範囲の値はグループ適用前の座標を維持する。グループは描画の外側に適用し、元画像の実ピクセル上で回転するため、縦長画像でも角度・比率を保つ。全素材の重なり順・表示条件は維持し、グループ別に並べ替えない。

## 保存・整理

通常のグループ設定だけなら作業ZIP版9の `expressionGroups` に変換・所属・範囲追従を保存する。旧版1〜8は設定なしとして復元し、見え方を維持する。旧アプリは版9を開けない。グループの動きのキーもある場合は版10になる。解除後は残る設定に応じた版で保存する。[動きのキー](GROUP_MOTION_KEYS.md)。

変換の移動は元画像の−100〜100%、中心は0〜100%、角度は−180〜180度、倍率は10〜400%。未知のグループ・役割、画像のない所属、余分なキー、文字列・範囲外の数値、所属/範囲のない追従等を拒否し、現在の作業を保持する。

素材削除でその役割の所属・追従を整理し、グループの変換は保持する。素材がなくても変換設定だけを保存・再開できる。素材置換では設定を維持。範囲/所属解除でその役割の追従も外す。新画像・リセットは全グループを整理する。素材/元画像/配置変更、作業読込・保存、他処理開始は専用画面を閉じる。回転・画面非表示・取消ジェスチャー・二本目の指では進行中のドラッグを戻す。

元PNG・制作素材ZIP・PSDを変えない。依存・起動手順・外部送信を追加しない。自然な表情の品質、実機スマホ、moc3出力・VTube Studio読込は未検証/未実現で、独自プレビューと区別する。

## 動作サンプル

画像を選ぶ前に「動作サンプルを試す」で自作図形から顔と11素材をブラウザ内で用意する。左右の目・口に既存の9点変形と表示切替を設定し、グループ・範囲追従・顔の左/中央/右の動きも用意。向きスライダーや複合再生を試せる。作業ZIPは版10になる。普段と同じ作業ZIPで保存・再開する。選択済みの作業があるときは入口を無効にし、サンプル生成中に元画像を選ぶと遅れてサンプルが置き換えない。失敗時は再操作できる。

サンプルにAI・外部画像・モデル生成は使わない。図形の動きは操作の確認用で、実キャラクターの分離品質を示さない。画像や生成ファイルをGitHubへ追加せず、描画コードだけ保存する。
