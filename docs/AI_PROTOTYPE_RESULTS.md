# AI 試作と自前評価の結果

2026-10-09（日本時間）。外部 AI API、課金、有料 GPU、公開、main マージは行っていない。

## 実装
- デモと AI 試作を選択できる。AI は各パーツの点または枠を指定してから実行する。
- タップ・ドラッグのほか、キーボードで百分率の座標を入力できる。
- Vite の /api 経由で localhost の FastAPI サーバーに画像と指定を送る。第三者へ画像を送らない。
- SAM 2.1 tiny を CPU で実行。元の RGB と alpha を保持し、選択したマスク外を透明にした元画像サイズの PNG を返す。
- サーバーは不正な画像・座標・重複 ID・大きすぎる画像を拒否する。未配置モデル、空の結果、実行中、処理失敗を表示する。デモへ自動的に置き換えない。
- CPU 処理は一度に一件。公開運用向けの認証やジョブ管理はない。

## 固定したモデルと環境
- Python 3.12.14、torch 2.5.1+cpu、torchvision 0.20.1+cpu。依存関係は server/requirements.txt と scripts/setup_ai.py に記録。
- NVIDIA デバイス・nvidia-smi は見つからず、torch.cuda.is_available() は False。利用可能な CPU を使い、torch のスレッド数を 4 に制限。
- SAM ソース: facebookresearch/sam2、コミット 2b90b9f5ceec907a1c18123530e92e794ad901a4（Apache 2.0）。
- SAM 重み: Meta の公式 URL https://dl.fbaipublicfiles.com/segment_anything_2/092824/sam2.1_hiera_tiny.pt 。TLS 検証を保って取得。
- 重み SHA-256: 7402e0d864fa82708a20fbd15bc84245c2f26dff0eb43a4b5b93452deb34be69 。初回公式取得後に記録した値であり、提供元が公開する署名とは異なる。再取得・初回モデル読込時に一致を検証する。
- BiRefNet-general-lite は rembg 2.0.85 の公式リリースへのダウンロード処理を利用。既定の MD5 検証を無効にしていない。
- scripts/setup_ai.py を現在の環境で実行し、再導入とモデル検証が成功。まっさらな端末・Windows での導入は未検証。

## 実際の推論結果

| 対象 | 入力と実行 | 結果 | 制約 |
|---|---|---|---|
| SAM パーツ指定 | 自作の図形 3 枚、各 4 領域、各 3 回。256 × 384 px、枠指定 | 起動後の一枚・4 領域: 1.635〜2.189 秒。初回: 4.083 秒。重なり率中央値 0.9976。プロセス最大 RSS 約 1.12 GiB | 単純な楕円等であり実キャラクターではない。1024 px の速度目標、半透明髪、左右の目、隠れ領域の精度は未評価 |

## 自動テスト
- 本番ビルド成功。
- ブラウザ: 9 件実行、9 件成功（既存操作 7 件、指定画面と未配置エラー 1 件、実 SAM 接続 1 件）。通常は 8 件、実モデル用テストは RUN_REAL_SAM=1 のとき追加される。
- サーバー: 6 件実行、6 件成功。PNG の色・alpha・座標保持、入力検証、モデル未配置と処理中、失敗後再試行、透明領域だけの拒否を検証。
- サーバー単体テストはマスクの代替処理を使って出力仕様を検証する。AI 動作の証拠は上記の実推論と実接続テスト。
- FastAPI の TestClient から使用している httpx について非推奨警告が一件ある。テスト失敗ではないが、依存更新時の対応対象。

## 残る課題
- 部分の名前を選ぶのは利用者。モデルが自動で髪・顔・衣装を認識して割り当てる仕組みではない。
- マスクの候補はモデルのスコアで選ぶ。結果が意図と異なる可能性があり、追加点・除外点・手動補正は未実装。
- ブラウザのリセットは通信と結果反映を中止するが、サーバーで始まった計算は完了まで続く。その間は次の依頼を拒否する。
- 10 MB 制限は API の画像読み込み時に確認。multipart の解析はそれより前に行われるため、公開前には受信全体の上限も必要。
- FastAPI の UploadFile は大きな入力を一時ファイルへ移すことがある。継続保存・学習利用はしないが、一時ファイルが全く作られない保証ではない。
- 大きい画像の実機負荷、サーバー計算中止・時間制限、認証、公開環境を含む運用設計は未完成。

## 再現
README の AI 試作手順に従いモデルとサーバーを準備する。評価は次のコマンド。

```sh
.venv/bin/python -m scripts.evaluate_sam
.venv/bin/python -m scripts.evaluate_background
.venv/bin/python -m pytest server/test_app.py -q
RUN_REAL_SAM=1 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

評価出力は /tmp に置き、元画像とモデル重みは GitHub に保存しない。自作テスト画像は実行時に生成する。
次の品質評価には利用権がある実キャラクター画像が必要。所有者から利用条件を確認し、第三者 API に送らずに自前処理する計画を提案する。
