# 表情素材を表示する範囲の試作

2026-10-10。オーナーの「続けて」による継続。追加した素材ごとに、元画像上に固定する長方形・楕円の表示範囲を設定する。輪郭を自動検出する機能ではない。

## 操作

1. 合成画面の「調整する素材」で対象を選ぶ。
2. 「選択素材を表示する範囲」で形と左端・上端・幅・高さを指定し、「表示範囲を反映」を押す。未設定では素材の配置を仮の範囲として入力するだけで、勝手に適用しない。
3. 「指で表示範囲を調整」では、数値入力を下書きの開始位置として使い、実際の合成を見ながら調整する。枠内をドラッグして移動、右下の点でサイズを変更する。素材の配置は動かさない。
4. 「大きさを変える」は現在の比率を保つ。「幅・高さを変える」は縦横を別々に変更。拡大1〜4倍、拡大画面の移動、矢印0.5%、大小5%、最大30操作の取り消し・やり直しに対応。
5. 「範囲を確定」で適用。閉じる・変更せず戻る・Escapeは元の設定を保持。数値入力の値だけでは合成を変更しない。「表示範囲の制限を解除」で素材全体を表示する。

範囲の位置は元画像全体に対して0〜100%、幅・高さは0.01〜100%。右端・下端が画像を越える指定は許可し、画像の外側は表示されない。再生・保存・他の処理中は編集を止める。素材や画像の変更・リセット時は専用画面を閉じ、借りた描画元の参照を解放する。取消されたドラッグ・回転時の進行中の操作は開始前に戻す。

## 描画と制限

範囲を指定した素材の描画だけにCanvasのクリップを適用し、他素材・背景には適用しない。重なり順・表示条件と併用し、変形途中の描画にも適用する。範囲は元画像上に固定され、配置変更・変形に追従しない。開閉に合わせた範囲の変形、素材の透明度からのマスク、自由な輪郭・親子関係は未対応。変形編集の点や線のガイドは確認用に範囲外にも表示する。

専用画面では編集中の素材の範囲だけを下書きで置き換えて合成し、明るい枠を重ねる。元画像の背景は合成画面で選んだ設定を使う。表示条件で素材が非表示なら、範囲を動かしても素材は表示しない。必要に応じて合成画面の開閉値・表示条件を調整してから編集する。

元PNG・制作素材ZIP・PSDを変えない。範囲は作業ZIPと独自プレビューだけの設定で、Cubism形式・VTube Studio用モデルではない。実キャラクターの自然な表情品質・実機スマホは未検証。

## 保存と検証

範囲がある場合だけ版8とし、`expressionClips`に役割別の `{shape:'rect'|'ellipse',x,y,width,height}` を保存する。各値は元画像に対する0〜1の割合。`expressionLayers`と`expressionDeforms`も含め、既存の設定を維持する。範囲を解除すると残った設定に応じて従来の版に戻る。旧版1〜7は範囲なしとして読める。旧アプリでは版8を読めない。

役割・対応画像・形・キー・有限数・範囲を検証する。不明な役割や画像のない役割、余分なキー、文字列の座標、ゼロのサイズ等は拒否し、開いている作業を保持する。素材の取り外しでその役割の範囲を外し、素材置換では設定を維持。新画像・リセットで全範囲を整理する。下書き・履歴・再生状態は保存しない。

`tests/expression-clips.spec.js`は自作図形で実画素、別素材・背景の維持、変形中の制限、元PNG維持、版8の保存・復元と不正設定の拒否、版7互換、解除・素材削除、実タッチの下書き・取消・確定とスマホ幅を検証する。ユーザー画像や派生画像をリポジトリへ保存しない。依存・外部送信・環境の起動手順は追加しない。
