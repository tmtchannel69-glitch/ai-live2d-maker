# パーツの確認記録

最新の「続けて」により、確認記録と端末の作業ファイル保存を実装。画像・記録のクラウド保存や新しい外部サービスは追加しない。

基本四分類と制作15項目すべてに境界状態、描き足しの必要性、メモを持てる。構成切替・選択解除で記録を失わず、結果がなくても必要作業を記録できる。集計は選択中のみ。メモは文字として表示し、HTMLとして実行しない。

境界は未確認・見える部分は確認済み・境界修正が必要。描き足しは未確認・必要・この用途では不要。「描き足し完了」は提供しない。確認済みの指定は現在の指定と一致するAI結果に限り、デモや結果なしには許可しない。指定変更前の結果に既存の確認済み記録があっても、集計から除外し再確認を案内する。

再分離・ブラシ反映で画像が変わった対象の境界は未確認へ戻す。描き足し「必要」とメモは保持し、「不要」は未確認へ戻す。分離失敗や補正のキャンセルでは記録を変えない。新しい有効画像の選択・リセットで全記録を消し、無効な入力では保持する。

画面内の変更を残すには作業ファイルを手動保存する。普通のPNG・素材ZIPには記録を含めない。確認記録は作業手順の整理であり、マスクの品質保証や完成したLive2Dモデルを示すものではない。
