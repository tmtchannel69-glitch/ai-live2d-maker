# 外部PNG 33パーツ総入れ替え：回帰検証

2026-10-25。一般公開前のオフライン品質ゲート。

## 検証ケース

1. 従来：2枚のみ外部画像に置換し、その他31枚のローカルテンプレート、実験用INP/INX、33画像入りZIP、レポートを検証。
2. 今回：基準デザインから33役割すべてについて独立したRGBA透過PNGの**テスト図形**を作り、iPhone向け複数ファイル選択で一度に取り込み。33枚が揃い、テンプレート0枚、Inochi2D構築1回、INP/INX、33枚の出力PNG寸法、SHA256、元の通常ZIPが不変であることを検証。外部API呼び出しは遮断・0件を期待。
3. 今回：有効な画像と「指定範囲外に画素がある画像」を同時選択し、後者を拒否した場合に実験用結果を公開せず、元の通常ZIPを変更しないことを検証。
4. 旧来：未知の役割・重複の拒否、極小パーツの警告、変更前/変更後の比較表示を継続検証。

## 重要な限界

- テストPNGは単色長方形のプログラム生成図形であり、ChatGPT製画像や実際の美術品質を検証したわけではない。
- PNGの構造・33枚の一貫した読み込み・INP/INXの生成は、顔・髪の隠れ領域補完、人体の自然さ、瞬き・髪揺れの美術品質を保証しない。
- 画像1枚からの完全自動33パーツ分離は未完成。ユーザーが既に分けたPNGをまとめて取り込む実験。
- 完成ファイルはInochi2D実験形式であり、正式なLive2D Cubism .moc3 やVTube Studio向け完成モデルではない。
- 課金API、外部送信、公開アプリへの自動デプロイは実行しない。
