# 表情を拡大して確認

合成・開閉画面の「表情を拡大して確認」から、追加した素材の重なり・開閉・変形・範囲・グループの動きを確認します。合成画面と同じ描画を使い、自然な表情の完成やLive2Dモデルの互換判定は行いません。

## 使い方

画像の表示領域と操作欄のスクロールを分け、開閉スライダーを操作しても画像が画面外へ流れない構成です。スマホ縦画面は画像が上、操作が下。横画面/PCでは画像と操作を左右に並べます。

- 確認する素材を選び、100 / 200 / 400%で拡大。「選んだ素材へ移動」は、その状態で描画される素材の位置へ400%で移動します。透明な余白を含む全キャンバスの素材にも対応します。
- 指で画像内をスクロールします。キーボードでは画像にフォーカスして矢印で移動できます。「全体を表示」で100%と先頭位置へ戻します。
- 「選択素材だけを確認」で、その一枚の変形・表示範囲・親子の動きを確認します。他の素材の重なりで隠れる場合は合成表示でも確認してください。
- 「元画像を薄く重ねる」で元位置と比較します。元画像は25%で背景に描き、元の目・口の絵は動きません。完成した合成の品質確認には、この比較表示を外して確認してください。
- 左目・右目・口・顔の向きのスライダーで確認する値を変更します。閉じた素材は開いた状態では表示されない場合があります。非表示・範囲外・完全透明など描画部分がなければ、素材へ移動する操作を無効にして案内します。
- 「この素材の表示/形/範囲を調整」から、対象素材の編集へ戻ります。確認していた開閉値を合成画面の一時的な値へ引き継ぎます。移動しただけでは設定を反映しません。

## 鮮明に確認

細い線がぼやける場合は「鮮明に確認」を押します。元PNGから確認用の画像を読み直し、描画する画素数を縦横それぞれ通常の2倍（最大1280×1920）にします。100/200/400%の拡大率と確認位置は保ちます。選択素材だけの表示、元画像比較、開閉/向き、編集への移動も使えます。「通常表示に戻す」で追加画像を解放します。

読込中も通常表示を操作でき、「読み込みを中止」で取り消せます。失敗した場合は通常表示と素材を保持し、再試行できます。画面を閉じる/編集へ戻る/保存・処理の開始/素材変更/リセット/ページ非表示では読込を無効にし、遅れて届いた画像も解放します。確認画面を開き直した際は通常表示から始まります。

素材の配置サイズに応じて必要な解像度を計算し、元画像比較用の画像と全素材の追加RGBA画素量を合計16MiB以内に縮小します。1枚ずつ読み込み、完成済みの高解像度の中間画像を別途保持しません。ただしこれはアプリ全体のメモリ上限ではありません。通常表示の画像、描画キャンバス、変形用の一時領域、ブラウザ内部でPNGを解凍する際の一時メモリは別に必要です。実機のメモリ/速度は未確認です。

## 保存と安全な復帰

拡大・移動・選択素材だけの表示・元画像比較・確認用の開閉値は、この画面の一時的な表示です。PNG、PSD、保存した配置/変形/範囲/グループ設定を変更しません。作業形式版1〜11を維持します。画面を開くと再生を停止し、戻る操作/Escapeで元の画面へ戻ります。編集へ移動した際は編集先へフォーカスします。

素材/元画像の変更・処理や保存の開始・リセット・ページが非表示になった際は確認画面を閉じます。画像の遅い読込から古い表示を復活させません。閉じた画面の表示用画素は消去します。通常表示には既存の縮小済みキャンバスと素材を使います。鮮明表示も端末内で元PNGから読み直し、確認のための外部送信・保存は行いません。

通常表示の拡大では縮小した画素が拡大されます。鮮明表示も元にない細部を復元せず、PNGの大きさ・配置・読込量の上限で画質が変わります。最終的なPNG/PSDの輪郭・色は画像編集ソフトで確認してください。自然な動き・実機スマホでの速度/メモリ・Cubism/VTube Studioへのモデル読込は別途検証が必要です。
