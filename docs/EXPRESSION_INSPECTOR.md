# 表情を拡大して確認

合成・開閉画面の「表情を拡大して確認」から、追加した素材の重なり・開閉・変形・範囲・グループの動きを確認します。合成画面と同じ描画を使い、自然な表情の完成やLive2Dモデルの互換判定は行いません。

## 使い方

画像の表示領域と操作欄のスクロールを分け、開閉スライダーを操作しても画像が画面外へ流れない構成です。スマホ縦画面は画像が上、操作が下。横画面/PCでは画像と操作を左右に並べます。

- 確認する素材を選び、100 / 200 / 400%で拡大。「選んだ素材へ移動」は、その状態で描画される素材の位置へ400%で移動します。透明な余白を含む全キャンバスの素材にも対応します。
- 指で画像内をスクロールします。キーボードでは画像にフォーカスして矢印で移動できます。「全体を表示」で100%と先頭位置へ戻します。
- 「選択素材だけを確認」で、その一枚の変形・表示範囲・親子の動きを確認します。他の素材の重なりで隠れる場合は合成表示でも確認してください。
- 「元画像を薄く重ねる」で元位置と比較します。元画像は25%で背景に描き、元の目・口の絵は動きません。完成した合成の品質確認には、この比較表示を外して確認してください。
- 左目・右目・口・顔の向きのスライダーで確認する値を変更します。閉じた素材は開いた状態では表示されない場合があります。非表示・範囲外・完全透明など描画部分がなければ、素材へ移動する操作を無効にして案内します。
- 「この素材の表示/形/範囲を調整」から、対象素材の編集へ戻ります。確認していた開閉値を合成画面の一時的な値へ引き継ぎます。移動しただけでは設定を反映しません。

## 保存と安全な復帰

拡大・移動・選択素材だけの表示・元画像比較・確認用の開閉値は、この画面の一時的な表示です。PNG、PSD、保存した配置/変形/範囲/グループ設定を変更しません。作業形式版1〜11を維持します。画面を開くと再生を停止し、戻る操作/Escapeで元の画面へ戻ります。編集へ移動した際は編集先へフォーカスします。

素材/元画像の変更・処理や保存の開始・リセット・ページが非表示になった際は確認画面を閉じます。画像の遅い読込から古い表示を復活させません。閉じた画面の表示用画素は消去します。表示には既存の縮小済みキャンバスと素材を使い、確認のために元画像を外部送信・保存しません。

確認用の拡大は原画像の高解像度復元ではありません。縮小プレビューの画素が拡大されるため、最終的なPNG/PSDの輪郭・色は画像編集ソフトで確認してください。自然な動き・実機スマホでの速度/メモリ・Cubism/VTube Studioへのモデル読込は別途検証が必要です。
