## 発見した問題と修正

1. 呼吸のキーが0/1だけだと公式GUIのShift操作で.5が端へ吸着した。新profileに中間.5キーを加えてモデルを再生成し、公式の全検査をやり直した。旧6制御生成器は変更していない。
2. スマホのモード切替文字が小さくなる新CSSを16pxへ戻した。狭い幅でも横溢れなく48px以上を維持。
3. ZIP準備中の中止でも遅れて保存が始まる余地があった。Blob準備後もsignalを照合して破棄し、実ダウンロード0を検査。
4. `pagehide`で常に描画資源を閉じると、キャッシュから戻った画面のプレビューが動かなくなる。persistedの場合は資源を保ち、再生だけを停止。
5. スマホで処理状況が画面外になるため、短い状況/中止欄を追従表示し、長い品質注記は通常位置へ分けた。初回生成後のプレビュー移動と「組み立てと動きを見る」を追加。
6. 再生成の出力先判定で`..private`やsymlinkによりGit内へ出る余地を閉じた。実在する親を解決し、Git外の新規ディレクトリだけに保存。
7. 初期のテスト側でUint8ArrayをPlaywrightのBuffer引数へ直接渡すミスを修正。スクリーンショットのレイアウト依存のPNG比較を、実Canvas画素の指紋比較へ変更して、画素が変わっていないことを検査した。
