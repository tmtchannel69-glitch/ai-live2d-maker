# スマホで閉じた・開いた形を調整する

合成・開閉の素材を選び、「指で形を編集」を開きます。点のドラッグに加え、「形全体をまとめて調整」から幅・厚み・位置を変更できます。

1. 「編集する形」で閉じた形／開いた形を選ぶ。
2. 幅・厚みは現在の9点の外接範囲の中心を保ち、5%ずつ変更。全体の移動は素材幅／高さの0.5%ずつ。
3. 「もう一方の形をコピー」は選んだ形をもう一方の9点で置き換える。もう一方自体は保持。
4. 「途中の形を確認」をチェックし、開き0〜1を動かして補間を見る。確認中は点・全体・履歴の編集と反映を止める。拡大と画面移動は使える。
5. チェックを外して編集に戻り、「形を反映」で確定。「変更せず戻る」・閉じる・Escapeは下書きを破棄。
6. 「作業を保存」で端末のZIPへ保存。GitHubには利用者の素材や編集内容を保存しない。

各操作は全9点をまとめて取り消し／やり直し可能（最大30操作）。選んだ形を切り替えても下書きと履歴を保持。形の切替は途中確認を解除し、スライダーを選んだ端の値へ戻します。途中確認の値やチェック状態は保存しません。

点の交差、折り返し、座標の範囲外は、途中の補間も含めて検査し、操作全体を拒否。直前の形と履歴を保持し、案内を表示します。数値の上限で点を一律に丸めて形をつぶす操作はしません。

元PNGは変更せず、既存の変形設定へ保存。作業ZIP版1〜12と制作引き継ぎ版1／2を維持し、新しい保存項目は不要。形を反映すると従来どおり表示条件を「常に表示」にし、既存の表情確認記録を再確認対象にします。

点を動かすキャンバスは選んだ素材とメッシュを単独表示します。「重なりを確認（下書き）」を開くと、別の合成プレビューで他の素材・表示範囲・親子変換を確認できます。反映後は合成・詳細確認・3状態比較でも確認してください。9点の変形であり、閉じたまぶた・口内部の新規画像生成や隠れ部分の描き足しは行いません。細くする操作だけで自然な表情が完成するとは限りません。moc3生成とVTube Studio読込は未実装です。

検証はクラウドChromiumのスマホサイズによるもの。実機での使いやすさと速度は別途確認が必要です。

## 編集中の重なりを確認

「重なりを確認（下書き）」を開くと、現在の下書きを反映した合成画像が表示されます。点の移動、全体調整、取り消し／やり直し、開閉の切替、途中の開きに合わせて更新します。画像と見出しは、下の調整ボタンへスクロールしても画面上部に残ります。背景・向き・説明は画像の下で別にスクロールします。不要なときは見出しを押して閉じます。

- 選択素材の変形だけを下書きに置き換え、配置・順序・他素材の表示条件・固定／開閉範囲・親子と向きのキーは保存済みの設定で描きます。
- 選択素材は反映後と同じ「常に表示」で描きます。「非表示」の設定は維持するため、範囲や他素材と合わせて見えない場合があります。
- 編集する形の開き（閉じる0／開く1、途中確認時はその値）を、下書きの対象である目／口へ設定。他の目／口は編集画面を開いた時の合成値を使います。
- 「確認の向き」は合成画面の向きから始め、下書きプレビューだけに適用。「確認の背景」で透明／元画像の位置確認を切り替えます。どちらも保存設定や合成画面の値を変えません。
- 閉じる／変更せず戻る／Escape／リセットは、下書きとプレビュー画素を破棄。開き直しは透明背景、合成画面の向きに戻ります。途中確認値・背景・向き・開閉状態を作業ZIPへ追加しません。

既存の縮小済み画像を使い、描画サイズは最大320×480（縦横比を維持）。細い線や小さい部位は、反映後の詳細確認で拡大・鮮明表示を使ってください。確認用画像の追加読込や外部送信は行いません。描画処理は合成画面と共有し、下書きは実際の設定へ反映するまで保持します。
