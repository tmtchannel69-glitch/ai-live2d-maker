# AI Live2D Maker

スマートフォン・PC で利用できるキャラクターパーツ準備用 Web アプリです。
Vite と Vanilla JavaScript で実装しています。

## 起動

Node.js 20.19 以上、または 22.12 以上を使用してください。この環境では Node.js 24 で確認しました。

```sh
cd /workspace/ai-live2d-maker
npm ci --cache /tmp/ai-live2d-npm-cache
npm run dev
```

## 基本操作

1. PNG・JPG・WebP の画像を選択、またはドロップします（最大 10 MB、各辺 4096 px 以下・1600 万画素以下）。
2. プレビューを確認して、髪・顔・体と衣装・目から対象を選択します。
3. 「パーツを分離する」を押すと、デモの切り出し結果が表示されます。
4. パーツ画像をタップすると拡大表示できます。「閉じる」または Escape キーで戻れます。
5. 各パーツの「PNG」で個別保存、「まとめて ZIP 保存」で表示中の全パーツを保存できます。
6. リセット、または画像の再選択で結果を消去します。

現在の分離は、元画像の決められた矩形領域を切り出すデモです。デモモードでは画像はブラウザ内で処理され、サーバーへ送信しません。点・枠で指定する AI 試作については下記の手順を参照してください。パーツ名の自動判定、隠れた部分の補完、Live2D モデル生成は未実装です。

## AI 分離処理の接続

`src/separator.js` の `separateParts` を API 実装へ置き換えられます。画面はこのモジュールを通じて処理を呼び出します。

```js
// 入力
{ file: File, parts: ['hair', 'face', 'body', 'eyes'], signal: AbortSignal }
// 戻り値: Promise<Array<...>>
[{ id: 'hair', name: 'hair.png', blob: Blob }]
```

選択された ID ごとに PNG の Blob を返してください。画面側がプレビュー用 URL とダウンロードリンクを作成します。例外は画面上に表示され、再実行できます。画像の再選択・リセット時は AbortSignal で処理を中止します。API の認証情報はフロントエンドに置かず、バックエンド側で管理してください。


## AI 試作（点・枠で指定する切り抜き）

最新の試作ブランチは `feature/project-save` です。デモモードの処理は引き続きブラウザ内です。
AI モードでは画像と点・枠をこのアプリの試作サーバーへ送り、CPU 上の SAM 2.1 で処理します。第三者 AI サービスへ送信しません。
認証や公開運用の対策は未実装なので、ローカル開発で使ってください。

Python 3.12 と Git を用意します。モデルと依存関係のダウンロードが必要です。GPU は不要です。

```sh
python3 scripts/setup_ai.py
# ターミナル 1: サーバーを起動（プロジェクトルートで実行）
.venv/bin/python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
# ターミナル 2: 画面を起動
npm ci --cache /tmp/ai-live2d-npm-cache
npm run dev -- --port 5173 --strictPort
```

Windows PowerShell の場合（Windows での AI 導入はまだ未検証）:

```powershell
py -3.12 scripts/setup_ai.py
# ターミナル 1
.\.venv\Scripts\python.exe -m uvicorn server.app:app --host 127.0.0.1 --port 8000
# 別のターミナル 2
npm.cmd ci
npm.cmd run dev -- --port 5173 --strictPort
```

画像を選び、「処理方式」を「AI 試作」に変更します。選択パーツごとに「切り抜く場所を指定」で ＋ 残す点・− 除く点を置きます。点は各パーツ合計 32 個までで、枠と組み合わせられます。除く点だけでは実行できないため、残す点または枠を追加してください。数値入力と、パーツ別の「一つ戻す」「やり直す」にも対応します。

全体の分離後は結果カードの「髪を修正」などから指定を変更し、「このパーツを再分離」を押すとそのパーツだけ更新します。他の結果と、失敗した際の以前の結果は保持します。指定だけ変更した結果には「以前の結果」と表示します。PNG / ZIP は表示中の結果を保存するため、変更後の指定を反映したい場合は再分離してから保存してください。指定を消す操作は指定のみ消し、画像の再選択・リセットは全指定・履歴・結果を消します。元画像・指定・反映済み結果は「作業ファイルを保存」で端末に保存できます。
出力は元画像と同じサイズの透明 PNG。隠れた部分は描き足しません。処理中のリセットは画面反映を止めますが、サーバーの計算自体は完了まで続きます。

モデル未配置の場合は `python3 scripts/download_sam.py` を実行してください。公式配布先 `dl.fbaipublicfiles.com` への通信許可が必要です。
`/api` は開発サーバーの転送機能を使います。`npm run preview` や単なる dist 配信では AI API 接続を提供しません。

## ブラシで輪郭を補正

AI 試作の結果カードにある「髪をブラシで補正」などを押します。デモは固定領域の切り出しで元画像とサイズが異なるため、ブラシ補正の対象は AI 結果です。

1. 「消す」で不要部分をなぞると透明になります。「元画像から戻す」で欠けた領域をなぞると、元画像の色と透明度を戻します。元画像にない部分や完全に透明な領域は描き足せません。
2. 太さは元画像の px 単位で 1〜200。拡大は 100 / 200 / 400%。「画面を移動」に切り替えると、拡大した画像をスクロールできます。補正するときはブラシに戻します。数値で点を置く操作もあります。
3. 「補正前」でこの画面を開いた時点の結果と比較できます。「元画像を薄く重ねる」は確認用で、PNG に含みません。
4. 一操作ごとの取り消し・やり直しができます。最大 100 操作、変更前の透明度データは 32 MiB まで。超えると古い履歴を整理し、表示します。補正そのものは保持します。長い操作は 4096 点で区切ります。
5. 「補正を反映」を押すとこのパーツだけ保存対象を更新します。個別 PNG / ZIP は補正後の結果になります。閉じる・Escape は未反映の変更を破棄し、以前の保存対象を保持します。

取り消し履歴は補正画面を閉じると消えます。再度開くと、直前に反映した結果から新しい補正を始めます。AI の再分離に成功したパーツはブラシ補正を新しい AI 結果で置き換えます。画像の再選択・リセット・ページ更新で画面内の作業は消えるため、素材は PNG / ZIP、続きから作業したい場合は作業ファイルを保存してください。

[ブラシの検証と制限](docs/BRUSH_CORRECTION.md)を参照してください。

## 作業ファイルを保存・再開

- 画像を選んだら、画面上部の「作業ファイルを保存」を押します。`ai-live2d-work.zip` のダウンロードが始まるので、端末に保管してください。
- 次回は「作業ファイルを開く」でそのファイルを選びます。元画像、処理方式、選択パーツ、点・枠、反映済みの結果とブラシ補正を復元します。AI 分離前の指定だけでも保存できます。
- 指定変更後に再分離していない結果には、読み込み後も「以前の結果」と表示します。復元直後に AI 処理や外部送信は行いません。AI サーバーなしでも結果の閲覧・ブラシ補正・再保存はできますが、AI の再分離にはサーバーの起動が必要です。
- 作業ファイルを開くと現在の作業を置き換えます。必要な場合は先に保存してください。読み込みに失敗した場合は現在の画像・指定・結果を保持します。確認中にリセット・別画像を選ぶと、その確認結果の反映を中止します。
- 点指定とブラシの取り消し履歴、未反映のブラシ補正は保存しません。補正を反映し、画面を閉じてから作業ファイルを保存してください。
- 全体は 100 MiB 以下、元画像は 10 MiB 以下、各パーツは 32 MiB 以下。画像の上限は従来と同じです。通常の「まとめて ZIP 保存」は素材だけの ZIP であり、作業の復元には使えません。

作業ファイルは元画像を含む暗号化されていない ZIP です。保存・読み込みはブラウザ内で行い、GitHub・このアプリのサーバー・第三者サービスにはアップロードしません。自動保存や端末間の自動同期はありません。別端末で再開する場合は、保存したファイルを自分で移してください。実機スマホのダウンロード・ファイル選択は未検証です。

[ファイル仕様と検証記録](docs/PROJECT_FILE.md)を参照してください。
