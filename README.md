# AI Live2D Maker

スマートフォン・PC で利用できるキャラクターパーツ準備用 Web アプリです。
Vite と Vanilla JavaScript で実装しています。

## 起動

Node.js 20.19 以上、または 22.12 以上を使用してください。この環境では Node.js 24 で確認しました。

```sh
cd /workspace/ai-live2d-maker
npm ci --cache /tmp/ai-live2d-npm-cache
npm run dev
```

## 基本操作

1. PNG・JPG・WebP の画像を選択、またはドロップします（最大 10 MB、各辺 4096 px 以下・1600 万画素以下）。
2. プレビューを確認して、髪・顔・体と衣装・目から対象を選択します。
3. 「パーツを分離する」を押すと、デモの切り出し結果が表示されます。
4. パーツ画像をタップすると拡大表示できます。「閉じる」または Escape キーで戻れます。
5. 各パーツの「PNG」で個別保存、「まとめて ZIP 保存」で表示中の全パーツを保存できます。
6. リセット、または画像の再選択で結果を消去します。

現在の分離は、元画像の決められた矩形領域を切り出すデモです。デモモードでは画像はブラウザ内で処理され、サーバーへ送信しません。点・枠で指定する AI 試作については下記の手順を参照してください。パーツ名の自動判定、隠れた部分の補完、Live2D モデル生成は未実装です。

## AI 分離処理の接続

`src/separator.js` の `separateParts` を API 実装へ置き換えられます。画面はこのモジュールを通じて処理を呼び出します。

```js
// 入力
{ file: File, parts: ['hair', 'face', 'body', 'eyes'], signal: AbortSignal }
// 戻り値: Promise<Array<...>>
[{ id: 'hair', name: 'hair.png', blob: Blob }]
```

選択された ID ごとに PNG の Blob を返してください。画面側がプレビュー用 URL とダウンロードリンクを作成します。例外は画面上に表示され、再実行できます。画像の再選択・リセット時は AbortSignal で処理を中止します。API の認証情報はフロントエンドに置かず、バックエンド側で管理してください。

## AI 試作（点・枠で指定する切り抜き）

最新の試作ブランチは `feature/material-assignment-preview` です。デモモードの処理は引き続きブラウザ内です。
AI モードでは画像と点・枠をこのアプリの試作サーバーへ送り、CPU 上の SAM 2.1 で処理します。第三者 AI サービスへ送信しません。
認証や公開運用の対策は未実装なので、ローカル開発で使ってください。

Python 3.12 と Git を用意します。モデルと依存関係のダウンロードが必要です。GPU は不要です。

```sh
python3 scripts/setup_ai.py
# ターミナル 1: サーバーを起動（プロジェクトルートで実行）
.venv/bin/python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
# ターミナル 2: 画面を起動
npm ci --cache /tmp/ai-live2d-npm-cache
npm run dev -- --port 5173 --strictPort
```

Windows PowerShell の場合（Windows での AI 導入はまだ未検証）:

```powershell
py -3.12 scripts/setup_ai.py
# ターミナル 1
.\.venv\Scripts\python.exe -m uvicorn server.app:app --host 127.0.0.1 --port 8000
# 別のターミナル 2
npm.cmd ci
npm.cmd run dev -- --port 5173 --strictPort
```

画像を選び、「処理方式」を「AI 試作」に変更します。選択パーツごとに「切り抜く場所を指定」で ＋ 残す点・− 除く点を置きます。点は各パーツ合計 32 個までで、枠と組み合わせられます。除く点だけでは実行できないため、残す点または枠を追加してください。数値入力と、パーツ別の「一つ戻す」「やり直す」にも対応します。

全体の分離後は結果カードの「髪を修正」などから指定を変更し、「このパーツを再分離」を押すとそのパーツだけ更新します。他の結果と、失敗した際の以前の結果は保持します。指定だけ変更した結果には「以前の結果」と表示します。PNG / ZIP は表示中の結果を保存するため、変更後の指定を反映したい場合は再分離してから保存してください。指定を消す操作は指定のみ消し、画像の再選択・リセットは全指定・履歴・結果を消します。元画像・指定・反映済み結果は「作業ファイルを保存」で端末に保存できます。
出力は元画像と同じサイズの透明 PNG。隠れた部分は描き足しません。処理中のリセットは画面反映を止めますが、サーバーの計算自体は完了まで続きます。

モデル未配置の場合は `python3 scripts/download_sam.py` を実行してください。公式配布先 `dl.fbaipublicfiles.com` への通信許可が必要です。
`/api` は開発サーバーの転送機能を使います。`npm run preview` や単なる dist 配信では AI API 接続を提供しません。

[評価結果と限界](docs/AI_PROTOTYPE_RESULTS.md)、[候補比較](docs/AI_EVALUATION.md)も参照してください。

[複数点の実画像評価](docs/MULTIPOINT_EVALUATION.md)も参照してください。

## ブラシで輪郭を補正

AI 試作の結果カードにある「髪をブラシで補正」などを押します。デモは固定領域の切り出しで元画像とサイズが異なるため、ブラシ補正の対象は AI 結果です。

1. 「消す」で不要部分をなぞると透明になります。「元画像から戻す」で欠けた領域をなぞると、元画像の色と透明度を戻します。元画像にない部分や完全に透明な領域は描き足せません。
2. 太さは元画像の px 単位で 1〜200。拡大は 100 / 200 / 400%。「画面を移動」に切り替えると、拡大した画像をスクロールできます。補正するときはブラシに戻します。数値で点を置く操作もあります。
3. 「補正前」でこの画面を開いた時点の結果と比較できます。「元画像を薄く重ねる」は確認用で、PNG に含みません。
4. 一操作ごとの取り消し・やり直しができます。最大 100 操作、変更前の透明度データは 32 MiB まで。超えると古い履歴を整理し、表示します。補正そのものは保持します。長い操作は 4096 点で区切ります。
5. 「補正を反映」を押すとこのパーツだけ保存対象を更新します。個別 PNG / ZIP は補正後の結果になります。閉じる・Escape は未反映の変更を破棄し、以前の保存対象を保持します。

取り消し履歴は補正画面を閉じると消えます。再度開くと、直前に反映した結果から新しい補正を始めます。AI の再分離に成功したパーツはブラシ補正を新しい AI 結果で置き換えます。画像の再選択・リセット・ページ更新で画面内の作業は消えるため、素材は PNG / ZIP、続きから作業したい場合は作業ファイルを保存してください。

[ブラシの検証と制限](docs/BRUSH_CORRECTION.md)を参照してください。

## 作業ファイルを保存・再開

- 画像を選んだら、画面上部の「作業ファイルを保存」を押します。`ai-live2d-work.zip` のダウンロードが始まるので、端末に保管してください。
- 次回は「作業ファイルを開く」でそのファイルを選びます。元画像、処理方式、選択パーツ、点・枠、反映済みの結果とブラシ補正を復元します。AI 分離前の指定だけでも保存できます。
- 指定変更後に再分離していない結果には、読み込み後も「以前の結果」と表示します。復元直後に AI 処理や外部送信は行いません。AI サーバーなしでも結果の閲覧・ブラシ補正・再保存はできますが、AI の再分離にはサーバーの起動が必要です。
- 作業ファイルを開くと現在の作業を置き換えます。必要な場合は先に保存してください。読み込みに失敗した場合は現在の画像・指定・結果を保持します。確認中にリセット・別画像を選ぶと、その確認結果の反映を中止します。
- 点指定とブラシの取り消し履歴、未反映のブラシ補正は保存しません。補正を反映し、画面を閉じてから作業ファイルを保存してください。
- 全体は 100 MiB 以下、元画像は 10 MiB 以下、各パーツは 32 MiB 以下。画像の上限は従来と同じです。通常の「まとめて ZIP 保存」は素材だけの ZIP であり、作業の復元には使えません。

作業ファイルは元画像を含む暗号化されていない ZIP です。保存・読み込みはブラウザ内で行い、GitHub・このアプリのサーバー・第三者サービスにはアップロードしません。自動保存や端末間の自動同期はありません。別端末で再開する場合は、保存したファイルを自分で移してください。実機スマホのダウンロード・ファイル選択は未検証です。

[ファイル仕様と検証記録](docs/PROJECT_FILE.md)を参照してください。

## 制作向けの15項目

「パーツ構成」で「制作向け・上半身15項目」を選びます。AI 試作で、使う項目だけチェックして点・枠を指定します。最初は未選択です。各パーツは一つずつ再分離・ブラシ補正・PNG 保存できます。

| 分類 | 項目 |
|---|---|
| 髪 | 前髪、横髪・左 / 右、後ろ髪 |
| 顔・首 | 顔の肌、首 |
| 目・眉・口 | 目・左 / 右、眉・左 / 右、口の見える部分 |
| 衣装 | トップス、ジャケット本体、袖・左 / 右 |

左右はキャラクター本人の左右で、正面画像では「左＝画面右」です。名前は保存する対象の名前であり、AI が名前から自動で分類する機能ではありません。目は見える領域の切り抜きで、白目・瞳・まぶた等の細分化や瞬き・開いた口の素材、隠れ部分の描き足しは別工程です。

- 基本の四分類のデモと AI は引き続き利用できます。構成の切り替えでは両方の選択・方式・指定・結果を保持し、既存結果を自動で分割・改名しません。
- 方式変更は表示中の構成の結果を消します。画像の再選択・リセットは両方の指定・結果を消します。
- まとめ分離は最大4パーツずつ順番に処理します。途中で失敗した場合は全体の結果を更新せず、以前の結果を保持します。再実行は先頭から行います。リセットで画面反映を止めますが、サーバー上の計算自体は完了まで続きます。
- 「まとめて ZIP 保存」は表示中の構成の結果だけを保存します。「作業ファイルを保存」は両方の構成の状態を保存します。
- 旧版の作業ファイル（版1）は基本の四分類として開けます。制作向けの状態を含む保存は版2で、以前のアプリでは読み込めません。四分類だけの状態は引き続き版1で保存します。ファイル上限100 MiB等は従来と同じです。

[実装・互換性・実画像の確認](docs/PRODUCTION_PARTS.md)を参照してください。

## パーツの確認記録
画像を選ぶと「パーツの確認記録」が表示されます。各項目の「確認を記録」で元画像と結果を切り替え、境界の確認状態、隠れ部分の描き足しの必要性、500文字までのメモを記録します。集計は選択中の項目だけです。デモ・結果なし・指定変更前の結果を新しく確認済みにはできません。

「作業ファイルを保存」で記録も保存できます。ページを閉じる前に保存してください。再分離・ブラシ補正の成功時は対象の境界を未確認へ戻します。描き足し「必要」とメモは保持し、「この用途では不要」は未確認へ戻します。詳細は [確認記録](docs/REVIEW_STATUS.md)。

## 確認記録付きの制作素材ZIP

1. 保存したい構成を選び、必要な項目にチェックを入れます。
2. 「確認記録付き 制作素材ZIP」を押し、`ai-live2d-materials.zip` を保存します。
3. ZIPを展開して `CHECKLIST.txt` の確認・不足一覧を読み、`parts/` のPNGを画像編集などに使います。

選択中の項目だけが対象です。結果がある項目はPNGを含め、結果がない項目も不足一覧に残します。未選択や別構成の素材は含めません。AI結果は元画像のサイズ・位置とブラシ補正を保ったまま保存します。指定変更前のPNGには再分離・再確認の案内を付け、確認済みの集計に入れません。デモ素材には固定領域の切り出しと明記します。

元画像は含みませんが、選択したPNGと作業メモを含みます。作業再開には別途「作業ファイルを保存」を使ってください。完成したLive2Dモデル・PSDではありません。詳しくは [制作素材ZIPの仕様](docs/MATERIAL_ARCHIVE.md)。

## レイヤー付きPSD（試作）

AI結果を準備し、出力する項目を選んで「レイヤー付きPSDを保存（試作）」を押します。`ai-live2d-parts.psd`を端末に保存します。選択中の結果がある項目だけを一項目一レイヤーにし、元画像のキャンバスサイズ・位置・透明度・反映済みブラシ補正を保ちます。未選択と別構成の結果、元画像、結果なしの項目は含みません。

レイヤー名は日本語名とIDです。重なり順は仮の初期順序なので、画像編集ソフトで調整してください。指定変更前の結果もそのまま保存し、画面に再確認を案内します。確認記録と不足一覧は「確認記録付き 制作素材ZIP」、作業再開は「作業ファイルを保存」を併用してください。

デモは元画像上の位置を復元できないためPSDの対象外です。出力はRGB・8ビット、色プロファイルの埋め込み・変換は未対応です。画像編集ソフトでsRGBとして色を確認・保存してください。Cubism・Photoshop等での実読み込み、実機スマートフォンは未検証です。PSDの読み戻し検証を、これらのソフトの対応保証とは扱いません。

試作の上限は、レイヤーと合成画像の展開後の画素量128 MiB、各入力PNG32 MiB、出力100 MiBです。上限を超えると選択項目を減らすか素材ZIPを使う案内を表示します。PSD作成は画面とは別の処理で行い、リセット・画像再選択で中止できます。[設計と検証](docs/PSD_EXPORT.md)。

## アプリ内の動きの試作

AIパーツを準備すると「04 動きの試作」で、選択した結果を元の位置に合成します。頭の傾きのスライダーと「揺れ・呼吸を再生」で動きを確認できます。調整するパーツを選び、支点X/Y・重なり順・揺れ幅・頭への追従を設定して「設定を反映」を押します。数値は仮の初期値なので、パーツの配置に合わせて調整してください。

支点などの設定は「作業ファイルを保存」に含まれます（設定がある場合は版4、旧版1〜3も読込可能）。以前のアプリでは版4を開けません。再開後の再生は手動で開始してください。プレビュー用の変形と順序はPNG・PSDには反映しません。

これはアプリ独自の平面変形の試作です。瞬き・口・立体的な顔の向き、Live2Dモデルの出力は未対応です。最終目標はVTube Studio等で使えるモデルですが、現在のプレビューやPSDをそのままVTube Studioへ読み込むことはできません。[対応形式の調査と開発方針](docs/MODEL_AUTHORING.md)を参照してください。


## 瞬き・口の動きの素材準備

画像を選ぶと、目・口・顔の肌の準備一覧が表示されます。「目の分離項目を選択」「口の分離項目を選択」で制作向けの構成へ切り替え、関連項目を追加で選択できます。既存の選択・指定・結果は保持します。「切り抜く場所を指定」から指定し、AI分離を行ってください。項目選択だけで画像は送信しません。

準備一覧は未選択の制作向けの結果も含み、未分離・指定変更あり・境界修正待ち等を反映します。「準備一覧を保存」で状態・メモ・次の確認項目をテキストに保存できます。画像は含まず、作業ファイルの代わりにはなりません。確認記録は既存の作業ファイルに保存され、再開時に一覧へ反映されます。

閉じた目・口内部・下地の肌・細分化した素材や変形設定は未確認です。見える境界の確認済みだけで表情の完成とは扱いません。[操作と素材・変形の設計](docs/EXPRESSION_PREPARATION.md)。瞬き・口は追加素材の画像切替試作を利用できます。追加素材の9点変形は下記の試作で利用できます。moc3出力はまだ未実装です。


## 追加の表情素材を読み込む

「表情素材の読み込み・位置合わせ」で、閉じた目・白目・瞳・まつげ・下地の肌・上唇・下唇・口内部などの役割を選び、用意したPNGを読み込めます。各PNGは10 MiB以下、各辺4096 px以下・1600万画素以下です。透明PNGを推奨し、一つの役割に一枚まで。画像はブラウザ内で扱います。

元画像または透明背景に選択した一枚を表示します。左端・上端・幅・高さを元画像に対する%で指定し、「配置を反映」で位置合わせします。初期配置は比率を保って中央に置きます。元画像と同じサイズの素材なら元のキャンバス位置を維持します。元画像に既に描かれた目・口は背景に残ります。

「作業ファイルを保存」で追加画像・役割・配置も保存します（素材ありは版5、旧版1〜4は読込可能）。以前のアプリでは版5を開けません。「この素材の元PNGを保存」で元の画像も保存できます。「この役割の素材を外す」は現在の作業の一役割だけ外します。追加素材は既存のPNG/ZIP/PSD出力や動作プレビューにはまだ含みません。開閉の形は下記の合成画面で編集できます。画像生成・VTube Studio用モデル出力は未対応です。[操作と保存仕様](docs/EXPRESSION_ASSETS.md)。


## 表情素材を重ねて開閉を試す

追加PNGを準備すると「表情素材の重なり・開閉の試作」で合成できます。左目・右目・口を別々のスライダーで開閉し、「瞬き・口の切替を再生」で自動のテスト再生を行えます。0.5未満を閉じる、0.5以上を開く状態として画像を切り替える試作で、滑らかな形の変化ではありません。

調整する素材を選び、順序・表示条件・表示対象を変更し「表示設定を反映」を押します。順序が大きいほど手前です。設定は作業ファイル版6に保存され、旧版1〜5は読み込めます。設定なしの保存は従来の版を維持します。再生状態・スライダー値は保存せず、復元後は自動再生しません。素材を外すとその表示設定も外します。

初期背景は透明で、追加素材だけを表示します。元画像は位置確認用です。既存の目や口の絵は背景に残り、必要な素材がなければ切替で部品が消えることがあります。既存AIパーツの頭・髪の動作画面とは別の試作で、PNG/ZIP/PSDの内容を変えません。9点による形の変化は下記の新機能で試せます。VTube Studio用出力は未対応です。[操作・保存・制限](docs/EXPRESSION_SWITCHING.md)。

## 表情素材の形の編集（独自プレビュー）

追加素材ごとに9点で「閉じた形」「開いた形」を編集し、左右の目・口のスライダーで途中の形も確認できます。点は数値入力で編集し、反映時に表示条件を「常に表示」に変えます。仮の閉じた形は縦に縮めるだけなので、自然な表情には素材と点の調整が必要です。作業ファイル版7で保存・再開でき、旧版1〜6も読めます。

変形の解除、選択中の形を元の矩形に戻す操作、点と線の表示、自動再生に対応します。元PNG・PSDは変わりません。表示範囲を長方形・楕円で制限できます。親子の動き・moc3出力は未対応です。[操作と制限](docs/EXPRESSION_DEFORMATION.md)。

## スマホでの形の編集

「指で形を編集」から、画像を見ながら点をドラッグできます。拡大を1〜3倍で切り替え、「拡大画面を移動」で見たい位置に移動します。近い点は「調整する点」で選び、矢印で0.5%ずつ微調整できます。取り消し・やり直しは最大30操作。「形を反映」で確定し、閉じる・「変更せず戻る」では元の設定を保ちます。保存は従来の作業ファイル版7です。

今後の開発はスマホでの作業を基準にします。現在はWebアプリで、iPhone/Androidへのアプリ配布・実機確認はまだ行っていません。[スマホ優先の方針](docs/MOBILE_UX.md)。

## スマホで工程を移動する

画面上の「画像・分離・確認・動き・保存」から各工程へ移動できます。各工程の「次」も使えます。移動しても画像・結果・設定は保持されます。「動き」には素材読込・表情編集・頭と髪の動きへの入口があります。長い画面を繰り返しスクロールする負担を減らします。

最後の「作業の保存・再開」から端末に作業ZIPを保存し、後日読み込んで再開できます。PNG・制作素材ZIP・PSDの出力は「結果と素材の出力へ」から行います。これらの素材出力と、再開用の作業ファイルを区別してください。VTube Studio用モデルの書き出しはまだ未対応です。

## 指で表情素材を配置する

素材を読み込んだら「指で位置を合わせる」を開きます。素材の枠をドラッグして移動し、「大きさを変える」で右下の点を動かすと、現在の縦横比を保って拡大・縮小できます。1〜4倍に画面を拡大でき、「拡大画面を移動」で見たい位置へ移動します。矢印は元画像に対して0.5%ずつ移動し、大小ボタンは現在のサイズに対して5%ずつ調整します。

最大30操作の取り消し・やり直しに対応し、「配置を確定」で合成プレビューにも反映します。閉じる・変更せず戻るでは元の配置を保持します。素材の見え方を薄くする操作は、この編集画面だけの表示です。元PNGや出力の透明度は変えません。配置は従来の作業ZIPへ保存できます。

## 目・口の素材を表示する範囲

合成画面で素材を選び、「選択素材を表示する範囲」で楕円または長方形を指定します。位置・幅・高さは元画像全体に対する割合です。「表示範囲を反映」で、その素材だけが枠の内側に表示されます。他の素材や元画像の背景は隠しません。

「指で表示範囲を調整」では、結果を見ながら枠を移動できます。「大きさを変える」は比率を保ち、「幅・高さを変える」は右下の点で縦横を別々に調整します。拡大・画面移動・矢印・取り消しも使えます。「範囲を確定」まで下書きとして扱い、閉じると元の設定を保ちます。数値入力だけでの調整もできます。

範囲は元画像上に固定され、素材の移動や変形には追従しません。「表示範囲の制限を解除」で元の表示に戻せます。設定ありの作業ZIPは版8になり、このアプリでは旧版1〜7も開けます。古いアプリは版8を開けません。元PNG・制作素材ZIP・PSDは変わりません。自然な目・口の輪郭やLive2D出力の完成を意味しません。[詳細](docs/EXPRESSION_CLIPPING.md)。

## 素材をまとめて動かす

合成画面の「素材をまとめて動かす」を開き、「役割に合わせてまとめる」で顔全体・左右の目・口へ素材を割り当てます。顔全体には子の目・口の動きも含まれ、目や口だけを個別に調整することもできます。下側の「素材のまとめ方と表示範囲」で、素材ごとの所属と範囲の追従を変更できます。

指の操作を移動・回転・大きさ・中心点から選びます。拡大、矢印、大小・回転ボタン、数値、取り消しも使えます。数値は「数値を下書きに反映」で確認し、「まとめ方を確定」で全体へ反映します。閉じる・変更せず戻るは元の設定を保ちます。元のPNG・素材ごとの配置は変えません。

グループ設定だけなら作業ZIP版9、スライダー用の動きもある場合は版10で保存し、旧版1〜9も開けます。以前のアプリでは新しい版を開けません。表示範囲は既定では元画像上に固定され、必要な素材だけ「表示範囲も一緒に動かす」を選べます。9点の輪郭を自動で写す機能は未対応ですが、開閉に合わせた2つの範囲を独立に編集できます。[操作・制限](docs/EXPRESSION_GROUPS.md)。

## 左・中央・右の動きを作る

合成画面の「スライダーで動く位置を設定」を開き、動かすグループと左・中央・右の位置を選びます。「この位置の動きを編集」で指の移動・回転・大小調整を行い、「この位置の動きを確定」で反映します。数値を使う場合は先に「数値を下書きに反映」を押します。閉じると編集前の状態を保ちます。

「顔の向きの試作」スライダーで3位置の間を滑らかに動かし、「向きと表情の動きを再生」で瞬き・口と一緒に確認できます。設定したグループの動きは通常のグループ配置を置き換えます。通常の配置を変更しても設定済みの3位置は変わりません。「通常の配置から3位置を作る」は3位置すべてを通常の配置に戻します。「このグループの動きを解除」で通常の配置へ戻せます。

動きは作業ZIP版10に保存されます。スライダーの現在値・再生状態は保存せず、再開は中央から始めます。元のPNG・素材ごとの配置・PSDは変わりません。顔の立体変形やVTube Studio用モデルの出力は未対応です。[操作と保存形式](docs/GROUP_MOTION_KEYS.md)。

## 素材を用意する前に試す

画像を選ぶ前に「動作サンプルを試す」を押すと、自作図形の顔と11素材を用意した状態で始められます。左右の目・口と顔の向きのスライダー、複合再生、左・中央・右の編集を試し、作業ZIPで保存・再開できます。画像を選択済みのときはサンプルの入口を無効にし、作業を置き換えません。

サンプルはブラウザ内で図形から作成し、AI・外部サービス・画像送信は使いません。実キャラクターの分離品質や自然な表情品質の証明ではなく、Live2Dモデル・VTube Studio用データでもありません。

## 開閉に合わせて表示範囲を変える

「選択素材を表示する範囲」で先に固定範囲を反映します。「編集する範囲」を閉じた範囲（0）または開いた範囲（1）へ切り替え、左目・右目・口のどのスライダーに合わせるか選びます。指での専用画面と数値入力で位置・幅・高さを調整し、「表示範囲を反映」または「範囲を確定」で保存します。編集画面では選んだ開閉位置の合成を確認でき、閉じると変更前の状態を保ちます。

閉じた範囲では「閉じた範囲を薄くする」で現在の入力範囲を中心から縦方向へ縮められます。反映後は開閉スライダーで途中の範囲も滑らかに動きます。グループへの追従や9点の形編集と併用できます。「範囲の開閉を解除」で保持している固定範囲へ戻します。固定範囲だけを編集しても、設定済みの2範囲は変わりません。

設定ありは作業ZIP版11で保存し、旧版1〜10も開けます。サンプルにも口の範囲の開閉を設定しました。元PNG・素材配置・PSDは変わりません。自由な輪郭やメッシュからの範囲自動生成、VTube Studio向けモデル出力は未対応です。[詳細](docs/EXPRESSION_CLIP_KEYS.md)。

## 動きの設定を一覧で確認する

「動き」の入口に「動きの設定チェック」を追加しました。顔全体・左右の目・口について、読み込んだ素材、表示の無効化、開閉時に表示する素材の有無、変形と範囲の使う値、所属、左・中央・右の設定を確認できます。詳細を開き、各行のボタンから対象の素材・表示・形・範囲・まとめ方・3位置の編集へ進めます。

各部位の「閉じた状態・半分・開いた状態」（顔は左・中央・右）でその状態を合成画面に表示します。合成画面にも「すぐ試す動き」と3つのボタンがあります。再生中なら停止し、選んだ値だけを変えます。設定や元画像は変更しません。「動きの確認一覧を保存」は画像なしのテキストです。設定を変えて保存した作業ファイルを開くと、一覧はその設定から作り直します。

確認候補は設定の有無から作る案内です。範囲や変形は用途によって不要な場合があり、候補ゼロでも自然な動きやLive2Dモデルの完成を保証しません。一覧の折りたたみや通常のプレビュー値は保存しません。表情の確認メモを反映した作業は版12で保存します。[仕様と確認内容](docs/MOTION_CHECKLIST.md)。

## 素材と動きの設定を引き継ぐ

「保存」工程から、全分離PNG・追加表情PNG・配置/表示/変形/範囲/親子/動きの設定と確認一覧を一つのZIPへ保存できます。元画像は含みません。独自形式で、Cubism/VTube Studioへの直接読み込みには未対応です。作業再開には別途作業ZIPを保存してください。[出力内容・操作と制限](docs/AUTHORING_HANDOFF.md)。

## 分離結果を動きの素材へ直接使う

「動き」の素材読込画面で役割を選び、「分離済みのAIパーツを使う」から補正済みPNGを元位置のままコピーできます。コピー後の素材は独立し、再分離しても自動更新しません。「保存」では追加した表情素材の位置と重なり順をそろえたPSDも取り出せます。動きの設定・表示範囲はPSDに含まず、作業/引き継ぎZIPで保持します。[使い方・保存の選び方](docs/PRACTICAL_MATERIAL_WORKFLOW.md)。VTube Studio用のモデル出力は未対応です。

## 表情を拡大して確認

合成画面の「表情を拡大して確認」で100/200/400%表示、選択素材の描画位置への移動、指でのスクロール、単独表示・元画像比較・開閉の確認ができます。そのまま対象素材の表示/形/範囲の編集へ戻れます。確認だけでは保存設定や画像を変えません。[操作と制限](docs/EXPRESSION_INSPECTOR.md)。

変形プレビューの三角形境界に出ていた細い隙間を改善しました。半透明の素材を含め、一枚ごとに合成してから重ねます。元PNG・PSD・保存した設定は変えません。[描画改善と検証範囲](docs/MESH_RENDERING_QUALITY.md)。

表情の詳細確認に「鮮明に確認」を追加。必要なときだけ元PNGから確認用画像を読み直し、通常表示より細い線を確認しやすくします。読込は中止/再試行でき、戻ると追加画像を解放します。[使い方と上限](docs/EXPRESSION_INSPECTOR.md)。

詳細確認の「3状態を並べて比較」で、目/口の閉じた・途中・開いた状態や、顔の左・中央・右を同じ範囲で見比べられます。スマホでは左右にスクロールし、各画像の「この状態を詳しく」から拡大と編集へ戻れます。[比較の使い方](docs/EXPRESSION_COMPARISON.md)。

## 表情素材の確認メモ

詳細確認で状態を選び、確認状態とメモを入力して「記録を反映」。その時の目/口/向きと単独表示・元画像比較を記録します。「記録した状態を表示」で見直せます。素材や設定の変更後は再確認が必要と表示し、メモは保持します。作業ZIP版12で保存・再開し、旧版1〜11も開けます。制作引き継ぎZIPと画像なし確認一覧にも記録を含めます。[操作と注意点](docs/EXPRESSION_NOTES.md)。

## 閉じた・途中の形の調整

「指で形を編集」の「形全体をまとめて調整」で、選んだ閉じた/開いた形の幅・厚み・位置を一度に変更できます。もう一方の形のコピー、取り消し、途中の開きの確認に対応。途中確認中は編集を止め、チェックを外してから反映します。元PNGと従来の保存形式を維持。[操作と制限](docs/SHAPE_ADJUSTMENTS.md)。

編集中に「重なりを確認（下書き）」を開くと、他の素材・表示範囲・親子の動きを合わせて確認できます。調整中も画像を画面上部に保ち、背景と向きの確認は設定を変えずに操作できます。[使い方](docs/SHAPE_ADJUSTMENTS.md)。

下書きの合成確認でも100/200/400%の拡大と指でのスクロールができます。「選んだ素材へ移動」で透明な余白を除いた描画位置を400%表示。「全体を表示」で戻ります。確認の操作だけでは画像・作業設定を変更しません。[操作と制限](docs/SHAPE_ADJUSTMENTS.md)。

## 目・口の編集ガイド

「動きの設定チェック」のガイドで、素材準備→表示/形の調整→開閉確認の順に進めます。左右の目・口ごとの不足素材と、選んだ素材の次の操作を案内し、読込・編集・拡大確認/メモへ移動できます。歯・舌や別の閉じた絵は用途に応じて準備。[使い方](docs/EXPRESSION_EDIT_GUIDE.md)。

分離結果をコピーする前に透明背景で確認し、コピー先と置換内容を確認できます。顔の下地・閉じた形・口内部など、役割別に必要な素材を案内します。[素材準備の操作](docs/PRACTICAL_MATERIAL_WORKFLOW.md)。
